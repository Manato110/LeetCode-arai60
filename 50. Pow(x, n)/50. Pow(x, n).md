## Step.0
まずは自力で解く  
問題の理解から  

Implement pow(x, n), which calculates x raised to the power n (i.e., x^n).  

Constraints  
```
-100.0 < x < 100.0  
-2^31 <= n <= 2^31 -1  
n is an integer.  
Either x is not zero or n > 0.  
-10^4 <= x^n <= 10^4    
```

凄くシンプルな問で、`x`の`n`乗を求める問題  
ただし、`x`、`n`は負の値も取り得る  
特に指数部分`n`は`-2^31 <= n <= 2^31 -1`ととても巨大な値も取り得る  
`x`を`n`掛けるような`O(n)`のアプローチでは時間が足りない気がする  

と考えたが、ほかにアイデアが思いつかなかったので、一旦書いてみる  
`x^n = 1/(x^(-n))`なので、  
`n`が負の値の場合は、`n`に絶対値をつけて`x`を`|n|`回掛け、  
最後に逆数を取っている

### 書いたコード 1
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        answer = 1
        for i in range(abs(n)):
            answer *= x
        
        if n > 0:            
            return answer
        else:
            return (1 / answer)
```
案の定、`n`が巨大な場合に`TLE`、そうなるよね  

コード1を書いた後に、別のアイデアが出てきた  
なるべく同じ値の塊に分解してあげて求めてみる方針  
`n`を自然数とする    
`n = 2m`と表せるとき、  
`x^n = pow(x, n) = pow(x, n/2) ^ 2`  
`n = 2m + 1`と表せるとき、
`x^n = pow(x, n) = pow(x, n//2) ^ 2 * x`  
のように、`n`を2で割り、小数点以下切り捨てしたものを使って表現できる  
これを再帰的に行えば、logn回の再起呼び出しで求められる  

扱いやすくするため、`n`が負の値の時は、絶対値をつけて計算し、最後に逆数を取る  
`n`が0の時は、`x^n = 1`とすればよい  

書いてみる  
### 書いたコード 2
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n == 0:
            return 1
        
        def pow_helper(x: float, n: int) -> float:
            if n == 1:
                return x
            elif n % 2 == 0:
                return pow_helper(x, n // 2) ** 2
            else:
                return pow_helper(x, n // 2) ** 2 * x
        
        if n > 0:            
            return pow_helper(x, n)
        else:
            return (1 / pow_helper(x, abs(n)))
```

### Geminiが書いたコード
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x = 1 / x
            n *= -1
            
        def pow_helper(x: float, n: int) -> float:
            if n == 0:
                return 1.0

            else:

```
`n`が負の値の時には、`x`を逆数にして、`n`に－をかけて正の値にする

なぜ自分が書いたコードでは動かず、AIが書いたコードで動くのかを調べた  
原因は、自分のコードで、`return pow_helper(x, n//2) ** 2`と書いてしまったところ  

自分は、`pow_helper(x, n//2) ** 2`と書けば、  
`pow_helper(x, n//2) * pow_helper(x, n//2)`のように、  
両方を再帰で求める手間が減り、  
`pow_helper(x, n//2)`を求めて、それを二乗するというようになると思っていたが、  
`pow_helper(x, n//2) ** 2`と`pow_helper(x, n//2) * pow_helper(x, n//2)`は、  
処理の内容が全く同じらしい  
勘違いしていた  

つまり、`k = logn`とすると、  
再帰呼び出し回数が`1 + 2 + 4 + 8 + ... + 2^k ≒ 2n - 1`回になってしまい、  
`n`が巨大な時に、処理が膨大になりすぎてしまう  

そこで、一時変数`half = pow_helper(x, n//2)`と置くことで、問題を回避している

while文でループ処理  
xのn乗に計算について、
 - nが偶数だったら, (x^2)^(n/2)を計算するように引き継ぐ
 - nが奇数だったら, (x^2)^(n-1/2) * xを計算するように引き継ぐ
としている

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x = 1 / x
            n *= -1
            
        result = 1.0
        factor = x
        while n > 0:
            if n % 2 == 1:
                result *= factor
            
            factor *= factor
            n // 2
            
        return result
```

ビットシフトに注目した解法  
例えば、`n = 13 = 1101(2)`のとき、  
`x^13 = x^8 * x^4 * x^1`のように分解できる  
よって、`x`を必要回数2乗していく中で、`a`ビット目が`1`の時に答えに乗算していく  
やっている内容自体は先ほどのコードとほとんど変わらない  

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x = 1 / x
            n *= -1
            
        result = 1.0
        factor = x
        
        while n > 0:
            if n & 1:
                result *= factor
            
            factor *= factor
            n >>= 1
            
        return result
```
