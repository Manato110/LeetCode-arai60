## Step.0
まずは自力で解く  
問題の理解から  

There is an integer array nums sorted in ascending order (with distinct values).  

Prior to being passed to your function, nums is possibly left rotated at an unknown index k (1 <= k < nums.length) such that the resulting array is [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]] (0-indexed). For example, [0,1,2,4,5,6,7] might be left rotated by 3 indices and become [4,5,6,7,0,1,2].  

Given the array nums after the possible rotation and an integer target, return the index of target if it is in nums, or -1 if it is not in nums.  

You must write an algorithm with O(log n) runtime complexity.  

 制約  
 ```
 1 <= nums.length <= 5000  
-104 <= nums[i] <= 104  
All values of nums are unique.  
nums is an ascending array that is possibly rotated.  
-104 <= target <= 104  
```

「回転操作」を、リストの先頭要素を末尾に付け替える操作と定義する  
昇順に並んだリストに対して、任意の回数だけ回転操作済みの入力リスト`nums`について、  
`target`の数字がどのインデックスにあるかを探索する  
もしないなら、`-1`を返す  

要素数は最大で5000、重複する要素はなく、時間計算量O(logn)にする必要がある  
また二分探索の出番  

前回の問題の考え方が応用できそう  
これから探索する範囲のインデックス`left`～`right`について、  
中央のインデックス`middle`を定義する  
 - `nums[middle] > nums[right]`のとき = 昇順の切れ目が探索範囲の後半にあるとき
   - 前半は昇順に並んでいるので、こちらの方が比較しやすい
   - `nums[left] <= target <= nums[middle]`のとき、  
     もしターゲットが存在するなら探索範囲の前半(`middle`以前)にあるので、  
     探索範囲を`left`～`middle`に絞れる
     
   - 成り立たないとき、ターゲットが存在するなら探索範囲の後半にあると考えられるので、  
     探索範囲を`middle + 1`～`right`に絞れる  

 - それ以外のとき = 昇順の切れ目が探索範囲の前半にあるとき  
   - 後半は昇順に並んでいるので、こちらの方が比較しやすい  
   - `nums[middle] < target <= nums[right]`のとき、  
     もしターゲットが存在するなら探索範囲の後半(`middle`より後ろ)にあるので、  
     探索範囲を`middle + 1`～`right`に絞れる
     
   - 成り立たないとき、ターゲットが存在するなら探索範囲の前半にあると考えられるので、  
     探索範囲を`left`～`middle`に絞れる

これで漏れ、重複なく範囲を絞りながら探索することが出来ているはず  
範囲が1つ(`left = right`)になったときに、要素を見て、  
`target`と一致していたらその要素のインデックスを、  
一致しないなら`-1`を返す  

時間計算量は、`O(logn)`, 空間計算量は`O(1)`  

コードに起こしてみる  
### 書いたコード1
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while left < right:
            middle = (left + right) // 2
            if nums[middle] > nums[right]: # 昇順の切れ目が後半
                if nums[left] <= target <= nums[middle]:
                    right = middle
                else:
                    left = middle + 1
            else: # 昇順の切れ目が前半
                if nums[middle] < target <= nums[right]:
                    left = middle + 1
                else:
                    right = middle
        
        if nums[left] == target:
            return left
        return -1
```

## Step.2
探索するときに、`nums[middle]`の値が`target`と一致しているか調べる方法を取り入れる  
### 書いたコード2
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while left <= right:
            middle = (left + right) // 2
            if nums[middle] == target:
                return middle
            
            if nums[left] <= nums[middle]: # 前半が全て昇順に並んでいるとき
                if nums[left] <= target < nums[middle]:
                    right = middle - 1
                else:
                    left = middle + 1
            else: # 後半が全て昇順に並んでいるとき
                if nums[middle] < target <= nums[right]:
                    left = middle + 1
                else:
                    right = middle - 1
        
        return -1
```
