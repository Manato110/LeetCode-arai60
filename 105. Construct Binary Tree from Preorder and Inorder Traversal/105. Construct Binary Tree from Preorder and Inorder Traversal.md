再帰で考える  
pre-order、in-orderともに、親ノードの値を境にして  
左部分木・右部分木におけるpre-order, in-orderのリストに分割できる  
`pre-order = [root.val, left-pre-order, right-pre-order]`  
`in-order = [left-in-order, root.val, right-in-order]`  
なので、親ノードをもとにリストをスライスして、  
スライス後のリストを用いて再帰的に左子ノード、右子ノードを構築する  

この場合、in-orderのスライスが問題で、  
pre-orderの先頭にある親ノードの値をもとに、in-orderでどこに親ノードがあるかを探す必要がある  

これはその時のin-orderのリスト長を`N`とすれば`O(N)`の操作であり、再帰のたびにこれを行うのは非効率  
間違いなく`O(N^2)`であるが、ほかに思いつかなかったのだから仕方がない  

大体の見積もり：リスト長は最大で3000なので、3000^2 / 10^7 = 900ms  
`O(N^2)`だからこれまでより結構大きい  
ノード一つに対する処理が少しでも多くなると`TLE`になるだろう、結構ぎりぎり

### 書いたコード1
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if preorder is None or inorder is None:
            return None

        root_val = preorder[0]
        root = TreeNode(root_val)

        root_index = inorder.index(root_val)
        left_preorder = preorder[1:root_index + 1]
        left_inorder = inorder[:root_index]

        right_preorder = preorder[root_index + 1:]
        right_inorder = inorder[root_index + 1:]

        root.left = self.buildTree(left_preorder, left_inorder)
        root.right = self.buildTree(right_preorder, right_inorder)

        return root
```

時間計算量：`O(N^2)`  
最悪の場合、例えば木が分岐せず左側に一直線につながっているような場合、  
毎回分割後の`preorder`で末尾まで調べる必要がある  
つまり、検索するリストの長さがN, N-1, ..., 2,1のようになっていく  
オーダーで言うと、`O(N)`かかる検索・リストのスライスを最大`N`回行うため、合計`O(N^2)`

空間計算量：`O(N^2)`  
最悪の場合、例えば木が分岐せず一直線につながっているような場合、  
毎回分割後の`preorder`、`inorder`を保持するスタックフレームがつくられるため、  
それぞれのリストの合計の長さが`N + (N-1) + ... + 2 + 1 = N(N + 1)/2 = O(N^2)`のようになっていく

もう一つ、リストをスライスするのではなく、分割する境界値を渡してあげる方法を思いついた  

初めは境界値を開始・終了のインデックスを`left`、`right`にしていたが、  
`node.left`と`node.right`と紛らわしいと感じたため、`start`、`end`に変える  
これで再帰のたびに分割されたリストを生成する必要がなく、元のリストのみで十分になり、空間計算量が`O(N)`に抑えられる  

`preorder_index`はヘルパー関数の外側で定義しているので、インスタンス変数になってもらうため`self.`をつける  

### 書いたコード 2
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder or not inorder:
            return None
        
        inorder_to_index = {val : index for index, val in enumerate(inorder)}
        self.preorder_index = 0

        def build_tree_helper(start, end):
            if start > end:
                return None
            
            root = TreeNode()
            root.val = preorder[self.preorder_index]
            self.preorder_index += 1

            middle = inorder_to_index[root.val]
            root.left = build_tree_helper(start, middle - 1)
            root.right = build_tree_helper(middle + 1, end)

            return root

        return build_tree_helper(0, len(inorder) - 1)
```

### 書いたコード 3
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder or not inorder:
            return None
        
        root = TreeNode(preorder[0])
        frontier = [root]

        inorder_index = 0
        for index in range(1, len(preorder)):
            previous_val = preorder[index]
            node = frontier[-1]

            if node.val != inorder[inorder_index]:
                node.left = TreeNode(previous_val)
                frontier.append(node.left)
            
            else:
                while frontier and frontier[-1].val == inorder[inorder_index]:
                    last_popped_node = frontier.pop()
                    inorder_index += 1
                
                last_popped_node.right = TreeNode(previous_val)
                frontier.append(last_popped_node.right)
            
        return root
```
