### 問題  
https://leetcode.com/problems/generate-parentheses/description/  

## Step.0
まずは自力で解く  
問題の理解から  

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.  

```python
Example 1:
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]

Example 2:
Input: n = 1
Output: ["()"]

Constraints:
1 <= n <= 8
```

括弧のペア数`n`が入力されて、`n`ペアの括弧が有効な並びになっている場合すべてを列挙する  
有効というのは、次のルールを満たしていること  
 - `(`が来たら必ず`)`が来る  
 - 先に`)`が来ない  

`n`が最大8なので、無効な場合も併せて、最大`(8*2)! = 16! = 2.09E14`通りの組み合わせ  
greedyに全て列挙 -> 有効か検証というのは難しそう  

ルールを満たしながら次の括弧をつけるかどうかを考えていった方が良さそう  
`partial_candidate`となる組み合わせについて、  
`(`の個数`num_left`と`)`の個数`num_right`の情報を付加して保持しておく  

`num_left > num_right`の時、
 - `num_left < n`ならさらに`(`を付け加えるか、`)`を付け加えることが可能
 - `num_left = n`なら`)`を付け加えることのみが可能

`num_left = num_right`の時、`(`を付け加えることのみが可能

これ以外の場合については、ルールを守れていない場合だから、考えなくてよい  
`num_right = n`のときに付け加えることが終了し、答えとなるリストにappendする  

一度このように書きだしたが、もう少し簡略化できると感じたので、修正  
 - `num_right == n`なら、出力するリストにappend
 - `num_left < n`なら、`(`を追加可能、追加した場合についてさらに探索
 - `num_right < num_left`なら、`)`を追加可能、追加した場合についてさらに探索

計算量について、  
`n`ペアの括弧で、有効な組み合わせの個数を`a(n)`とおく  
`a(n + 1)`について、  
`a(n)`の中に`()`をルールを守って挿入することを考えると、  
`a(n)`を`a(k)`と`a(n-k)`に分割して、`( a(k) ) a(n-k)`か、`a(k) ( a(n-k) )`のように分けられる  
それぞれ、`a(k)a(n-k), a(n-k)a(k)`通りできると考えられて、`k = 0, ..., n`まで足し合わせると、  
ダブルカウントを考慮して、  
`a(n + 1) = a(0)a(n) + ...+a(k)a(n-k) + ...+a(n)a(0)`  

一般項を求められなさそうだったので、断念  
後でAIに聞くと、これはカタラン数の考えを適応して、次のように求められる  
`a(n) = 1/n+1 * (2n)! / n! = (2n)! / (n+1)!`  
よって、`a(n)`個の組み合わせに依存した回数処理を行う  
それぞれ、括弧の追加には`O(n)`かかるので、合計の時間計算量`O(n * a(n))` = `O(n!)`  

空間計算量について、再帰・DFSなら、組み合わせを作成していく樹形図を基に考えると、  
深さ`2n`のところまで一度に探索していくので、`O(n)`  
BFSなら、最大で深さ`2n`のところでの組み合わせを全て保持するので、`O(n * a(n))` = `O(n!)`   

再帰・DFS・BFSで書いてみる   
バックトラッキングを使った再帰で書くのが書きやすいと感じたので、再帰から書く  
### 書いたコード 1 (recursion)

```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        parenthesis = []

        def build_valid_parentheses(partial_parentheses: str, num_left: int, num_right: int):
            if num_right == n:
                parenthesis.append(partial_parentheses)
                return
            
            if num_left < n:
                build_valid_parentheses(partial_parentheses + "(", num_left + 1, num_right)
            
            if num_right < num_left:
                build_valid_parentheses(partial_parentheses + ")", num_left, num_right + 1)

        build_valid_parentheses("", 0, 0)
        return parenthesis
```

### 書いたコード 2 (DFS)
```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        parenthesis = []
        frontier = [("", 0, 0)]

        while frontier:
            partial_parentheses, num_left, num_right = frontier.pop()
            if num_right == n:
                parenthesis.append(partial_parentheses)
            
            if num_right < num_left:
                frontier.append((partial_parentheses + ")", num_left, num_right + 1))
            
            if num_left < n:
                frontier.append((partial_parentheses + "(", num_left + 1, num_right))
        
        return parenthesis
```

### 書いたコード 3 (BFS)
```python
from collections import deque


class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        parenthesis = []
        frontier = deque([("", 0, 0)])

        while frontier:
            partial_parentheses, num_left, num_right = frontier.popleft()
            if num_right == n:
                parenthesis.append(partial_parentheses)
            
            if num_left < n:
                frontier.append((partial_parentheses + "(", num_left + 1, num_right))

            if num_right < num_left:
                frontier.append((partial_parentheses + ")", num_left, num_right + 1))

        return parenthesis
```

```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        if n == 0:
            return [""]  # 0ペアの場合は空文字列のみ
        result = []
        for i in range(n):
            # A を i ペアで生成
            for A in self.generateParenthesis(i):
                # B を n-1-i ペアで生成
                for B in self.generateParenthesis(n - 1 - i):
                    result.append("({}){}".format(A, B))
        return result
```
