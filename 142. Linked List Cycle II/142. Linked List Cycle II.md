```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        current_node = head
        visited_nodes = set()

        while current_node:
            if current_node in visited_nodes:
                return current_node
            
            else:
                visited_nodes.add(current_node)
                current_node = current_node.next
        
        return None
```

類題(141.Liked List Cycle II)で受けたアドバイスを経て、変数の宣言を修正しました。

問題141とは違い、サイクルがあるならそのはじめを出力するとのことなので、```current_node```を返すようにしています。

pythonでは```null```を```None```で表現するので、サイクルがないなら```None```を返しています。
