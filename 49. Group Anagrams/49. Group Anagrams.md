## Step.0  
まずは自力で解くことを考える  
&nbsp;  
アナグラムを考えるということだが、要するに使用する文字の種類と数が一致しているということ  
前から順に文字列を見ていって、使用文字・種類が同じグループに割り振ることができたらいいかな？  
&nbsp;  
同じグループの分け方は、(もっといい方法がありそうだが一旦)、  
文字をアルファベット順に入れ替えたもの  を求めて使用する  
(例えば、`acb`, `bca`は、どちらも`abc`のグループ)  
&nbsp;  
結局すべての要素を見る必要があるし、計算量的にも悪くなさそう(自信ない)  
&nbsp;  
言い直すとこんな感じ  

 - 使用文字・種類が同じ文字列ごとに格納する辞書`anagram_group`を用意
 - `str`の要素を前から見ていく(=`word`とおく)
   - `word`の中身を、アルファベット順に並び替えた`sorted_word`を求める
   - `sorted_word`が`anagram_group`にないなら、新しくリストを作る
   - `sorted_word`が一致するグループに格納する
 - 辞書の要素を最後に出力する グループ名は出力しないように

以上をコードを起こしてみる  
&nbsp;  
はじめ、最後の`return`部分をどう書けばよいのか迷った  
`anagram_group`そのものではなく、値のみをリストにして返すことで目的の形状になる  

### 書いたコード1
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagram_group = {}
        for word in strs:
            sorted_word = "".join(sorted(word))

            if sorted_word not in anagram_group:
                anagram_group[sorted_word] = []

            anagram_group[sorted_word].append(word)

        return list(anagram_group.values())
```
ACになりひとまず安心  
&nbsp;  
時間計算量：各文字列の平均長を`L`とすると、ソート部分で`O(LlogL)`、これを`strs`の要素分おこなうため、合計`O(NLogL)`  
空間計算量：`strs`の要素分格納するので、`O(N)`

- `defaultdict(int)`: 新しいKeyが来たら`0`を作る

### 書いたコード2
```python
from collections import defaultdict
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagram_group = defaultdict(list)

        for string in strs:
            sorted_string = "".join(sorted(string))        
            anagram_group[sorted_string].append(string)
        
        return list(anagram_group.values())
```
