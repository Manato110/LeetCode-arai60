# Step.0　まずは参考文献なしに
validになる条件は言い換えると次の通り

- 左から順にカッコを見ていって、出てきた左カッコは覚えておく必要がある  
- 右カッコが出てきたとき、最後に出てきた左カッコとマッチするやつか確認  
  - 一致しないならinvalid
  - 一致するなら問題なし、その一つ前に登場した左カッコを思い出し、<br>それに1対1対応する右カッコが登場するか見る
- 上を繰り返して、最後まで到達したときに、登場してきた左カッコと対応する右カッコが同数になる  

&nbsp;  
以上を踏まえて、もう少しわかりやすくかみ砕く　　

- 登場する左カッコをストックするリストを用意する  
- 左カッコが登場してきたら順にリストに入れていく  
- 右カッコが登場したら、リストの最後に入れた左カッコと対応するか調べる  
  - 合っているなら、リスト最後の左カッコを削除
  - 違っているなら(またはそもそもリストに左カッコがないなら)、その文字列はinvalid  
- 最後にリストを見て、リストが空ならvalid、そうでないならinvalid  

かみ砕いた方をコードにおいてみる  
stackは空リストで宣言するとして、カッコの対応をどう落とし込むか...  
絶対に他にうまい方法があると思いつつ、愚直に対応するかif文で照らし合わせる方針で書いてみる

### 書いたコード
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []

        for char in s:
            # 左カッコなら、リストに追加
            if char == '(' or '{' or '[':
                stack.append(char)
            
            # 右カッコなら、対応する左カッコが末尾にあるかチェック
            elif char == ')' and stack[-1] == '(':
                stack.pop()
            elif char == '}' and stack[-1] == '{':
                stack.pop()
            elif char == ']' and stack[-1] == '[':
                stack.pop()
            
            # どれも当てはまらないならinvalid
            else:
                return False
        
        # 最後にリストが空ならvalid
        if stack == []:
            return True
        else:
            return False
```

# Step.1　Step.0のデバッグ
geminiより、大きく分けて2か所ミスしていることを指摘を受けた

### 1.左カッコに関するif文の書き方
pythonでは、比較演算子`=`の方が、論理演算子`or`よりも先に計算される  
そのため、  
`char == '(' or '{' or '['` 
は  
`(char == '(')` or `('{')` or `('[')`と解釈されてしまう  
カッコは非空文字なので、`('{')`、`('[')`はTrueとなる  
そのため、if文の条件部分は常にTrueで実行され、分岐が起こらない  
...ということが起こっていた  
&nbsp;  
修正として、`in`演算子を使って`char`が左カッコのいずれかになるなら、という感じに記述  
修正前`if char == '(' or '{' or '[':`  
修正後`if char in ('(', '{', '[' ):`  

### 2.`char`が右カッコの場合の処理
`char`が右カッコのときに、リストの末尾が対応する左カッコかを見ていたが、  
例えば文字列`s`が右カッコから始まる場合、まだ空リストの`stack`に対して`stack[-1]`と末尾を参照しようとしており、  
インデックス範囲外となる
&nbsp;  
修正として、そもそもリストが空かを先に確認するように修正  
&nbsp;  
修正前  
```
elif char == ')' and stack[-1] == '(':
  stack.pop()
elif char == '}' and stack[-1] == '{':
  stack.pop()
elif char == ']' and stack[-1] == '[':
  stack.pop()
``` 
修正後  
```
elif stack != []
  if char == ')' and stack[-1] == '(':
    stack.pop()
  elif char == '}' and stack[-1] == '{':
    stack.pop()
  elif char == ']' and stack[-1] == '[':
    stack.pop()
```

### 修正後の全体コード
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []

        for char in s:
            # 左カッコなら、リストにpush
            if char in ('(', '{', '[' ):
                stack.append(char)
            
            # 右カッコなら、対応する左カッコが末尾にあるかチェック
            elif stack != []: # リストが空か確認
                if char == ')' and stack[-1] == '(':
                    stack.pop()
                elif char == '}' and stack[-1] == '{':
                    stack.pop()
                elif char == ']' and stack[-1] == '[':
                    stack.pop()
            
            # どれも当てはまらないならinvalid
            else:
                return False
        
        # 最後にリストが空ならvalid
        if stack == []:
            return True
        else:
            return False
```
修正後のコードで、無事Accept  
今回の問題では入力が非空文字列であることが保証されているが、  
もし空文字列があり得る(そしてそれがtrueに分類される)場合なら、  
まず`s`が非空文字列か判別する必要がある  
&nbsp;  
時間計算量:O(N)　文字列の全ての文字を見る必要があるため、文字列の長さに比例
空間計算量:O(N)　最悪のばあ、文字列を全てリストに入れる必要がある

# Step.2　参考文献を活用し、コード改善

### 1.辞書によるカッコの対応づけ
pythonの文法の一つである辞書をもとに、
Key...右カッコ、Value...左カッコとして対応付ける  
例: `mapping = {')': '(', '}': '{', ']': '['}`  
これによって、右カッコに対する処理をまとめて記述できる  
&nbsp;  
修正前  
```
elif stack != []: # リストが空か確認
  if char == ')' and stack[-1] == '(':
    stack.pop()
  if char == '}' and stack[-1] == '{':
    stack.pop()
  if char == ']' and stack[-1] == '[':
    stack.pop()
```
修正後  
```
mapping = {')': '(', '}': '{', ']': '['}
if char in mapping:
  if not stack or stack.pop() != mapping[char]:
  return False
```
### 2.最後の判定部分の簡略
最後のリストが空かの判定(の逆の)結果を返せば、if文を書かずに済む  
&nbsp;  
修正前  
```
# 最後にリストが空ならvalid
        if stack == []:
            return True
        else:
            return False
```
修正後  
`return not stack`  

### 修正後の全体コード
```python
class Solution:
    def isValid(self, s: str) -> bool:
        # 対応関係を表す辞書
        mapping = {')': '(', '}': '{', ']': '['}
        stack = []

        for char in s:
            # 右カッコが来た場合
            if char in mapping:
                # リストが空、または対応する左カッコがリスト末尾にないならfalse
                if not stack or stack.pop() != mapping[char]:
                    return False

            # 左カッコが来た場合はリストに追加
            else:
                stack.append(char)
        
        # 最後にリストが空でないならtrue
        return not stack
```
&nbsp;  
時間計算量:O(N)　文字列の全ての文字を見る必要があるため、文字列の長さに比例
空間計算量:O(N)　最悪のばあ、文字列を全てリストに入れる必要がある
