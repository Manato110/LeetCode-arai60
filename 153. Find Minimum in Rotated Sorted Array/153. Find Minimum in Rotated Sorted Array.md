## Step.0
まずは自力で解く  
問題の理解から  

Suppose an array of length n sorted in ascending order is rotated between 1 and n times.  
Given the sorted rotated array nums of unique elements, return the minimum element of this array.  
You must write an algorithm that runs in O(log n) time.  

長さ`n`の昇順に数字が並んだリストをある回数だけ、末尾の要素を先頭に組み替える操作を行う  
例えば、`nums = [0,1,2,4,5,6,7]`のとき、  
4回末尾要素を先頭にする操作をすれば、`nums = [4,5,6,7,0,1,2]`になる  
入力`nums`で最小の要素を`O(logn)`で求める  

`O(n)`で良いなら、単に`min(nums)`で終了だが、`O(logn)`ならちょっと工夫する必要があるか  

制約  
```
n == nums.length
1 <= n <= 5000
-5000 <= nums[i] <= 5000
All the integers of nums are unique.
nums is sorted and rotated between 1 and n times.
```
入力リストは空ではないことが保証されている  
要素数、最大でも5000しかない  
`O(logn)`で書くことを要求する問題なら、もっと要素数大きくして`O(n)`では通らないようにするのかと思った  

最小値を求めるというタスクで、
O(logn)で考えるとしたら探索範囲を半分にしながら範囲を絞っていく感じが良いかな
これから探索する部分について、左端`left`、中央`middle`、右端`right`の要素を見る  

探索対象となる最小値`target`は、`middle`を含む前側か、後ろ側どちらかにあるはず  
テストケースで考える  `nums`と、左端、中央、右端の要素で大小関係を見る  

0123456 0 < 3 < 6  
6012345 6 > 2 < 5  
4560123 4 > 0 < 3  
2345601 2 < 5 > 1  
1234560 1 < 4 > 0  

テストケースで分かったこと   
 - 3つのうち`middle`の要素が最大の時、最小値は`middle + 1`～`right`の中にある
   - よってこの時は`left = middle + 1`と更新して、次の探索範囲を半分に絞れる
   - `middle`が最大なら、`left` > `right`が成り立つことと、`middle`が求めている最小値にならないことは明らか  
   - `middle`の要素 > `right`の要素なら、最小値が`middle`より後ろ側にあるはずだから、この2つの比較で十分だろう  

 - 3つのうち`left`または`right`の要素が最大の時、最小値は`left`～`middle`の中にある 
   - よってこの時は、`right = middle`と更新して、探索範囲を半分にできる
   - 実装上は、上のケースが成り立たないときに、この処理をする

最終的に、`left = right`になったら(探索範囲の長さが1になったとき)終了して、その時の要素を返せば行けそうか  

今回、探索する範囲は閉区間で考えています  
つまり、端点も探索対象として`[left, right]`を探索範囲に考える  
今回はこの方が考えやすいし、扱いやすいと感じた  
どの範囲を探索していて、逆にどこを探索していないのかを明確にしやすいように感じる  
`left`の初期値は`0`、`right`の初期値は`len(nums) - 1`になる

これなら、時間計算量は`O(logn)`、  
時間計算量は`O(1)` (保持する値は`left`, `right`であり、これは入力の長さに依存しない)  

コードを書いてみる
### 書いたコード1
```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        left = 0
        right = len(nums) - 1

        while left < right:
            middle = (left + right) // 2
            if nums[middle] > nums[right]:
                left = middle + 1
            else:
                right = middle
        
        return nums[left]
```
