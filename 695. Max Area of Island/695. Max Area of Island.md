問題の設定は前に解いた問題(https://leetcode.com/problems/number-of-islands/)と全く同じ  
今度は、島の数ではなく、最大の島の面積を求める問題  
前に書いたコードを少しいじったらいけそうでは...？  
前問を昨日解いたのもあり、アイデアは1つすぐに思いついた  

島の面積の最大値が分かればよいので、最大値のみ保持・更新するようにする  
2位以下の島の面積は覚えないことにする  

 - 島の面積の最大値`largest_island_area`を`0`で初期化  
 - DFS(深さ優先探索)で島の面積を計算する関数`measure_island_area`を定義
   - `row`行目`col`列目の地点`grid[row][col]`を見て、  
     それが入力の範囲外・水である・到達済みのいずれかだった場合探索を終了
   - 今見ている地点を到達済み(`visited[row][col] = True`)にして、島の面積`island_area`を1増やす
   - 今見ている地点から上下左右(`[row-1][col]`,`[row+1][col]`,`[row][col-1]`,`[row][col+1]`)について、
     `measure_island_area`を再帰呼び出し
 - すべての地点(要素)を順に見ていき、その地点が陸地かつ未達なら`measure_island_area`で面積を求める  

上のアイデアをコードにする  
### 書いたコード1
```python
class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        num_rows = len(grid)
        num_cols =len(grid[0])
        visited = [[False] * num_cols for _ in range(num_rows)]
        largest_island = 0

        for row in range(num_rows):
            for col in range(num_cols):
                if grid[row][col] == '1' and not visited[row][col]:
                    island_area = 0
                    self.measure_island(row, col, num_rows, num_cols, grid, visited, island_area)
                    largest_island = max(largest_island, island_area)
        
        return largest_island

    def measure_island(self, row, col, num_rows, num_cols, grid, visited, island_area):
        if not (0 <= row < num_rows and 0 <= col < num_cols):
            return
        if grid[row][col] == '0':
            return
        if visited[row][col]:
            return
        
        visited[row][col] = True
        island_area += 1

        self.measure_island(row - 1, col, num_rows, num_cols, grid, visited, island_area)
        self.measure_island(row + 1, col, num_rows, num_cols, grid, visited, island_area)
        self.measure_island(row, col - 1, num_rows, num_cols, grid, visited, island_area)
        self.measure_island(row, col + 1, num_rows, num_cols, grid, visited, island_area)
```

class Solution:
    WATER = 0
    LAND = 1
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        num_rows = len(grid)
        num_cols =len(grid[0])
        visited = set()
        largest_island_area = 0

        def measure_island_area(row, col):
            if not (0 <= row < num_rows and 0 <= col < num_cols):
                return 0
            if grid[row][col] == self.WATER:
                return 0
            if (row, col) in visited:
                return 0
            
            visited.add((row, col))

            island_area = (
                1 + 
                measure_island_area(row - 1, col) + 
                measure_island_area(row + 1, col) + 
                measure_island_area(row, col - 1) + 
                measure_island_area(row, col + 1)
                )
            return island_area
        
        for row in range(num_rows):
            for col in range(num_cols):
                if grid[row][col] == self.LAND and (row, col) not in visited:
                    largest_island_area = max(largest_island_area, measure_island_area(row, col))
        
        return largest_island_area

BFS(幅優先探索)による解法にもトライ  
開始した地点から見て、同じ深さのところを適宜キューに入れて必要な時に取り出していく  
Geminiと相談しながら作成  
```python
from collections import deque

class Solution:
    LAND = 1
    WATER = 0
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        num_rows = len(grid)
        num_cols = len(grid[0])
        visited = set()
        largest_island_area = 0

        def measure_island_area(row, col):
            queue = deque([(row, col)])
            visited.add((row, col))
            island_area = 0

            while queue:
                row, col = queue.popleft()
                island_area += 1

                for delta_row, delta_col in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                    next_row, next_col = row + delta_row, col + delta_col
                    
                    if (0 <= next_row < num_rows and 0 <= next_col < num_cols and 
                        grid[next_row][next_col] == self.LAND and (next_row, next_col) not in visited):
                        visited.add((next_row, next_col))
                        queue.append((next_row, next_col))
            
            return island_area

        for row in range(num_rows):
            for col in range(num_cols):
                if grid[row][col] == self.LAND and (row, col) not in visited:
                    largest_island_area = max(largest_island_area, measure_island_area(row, col))
        
        return largest_island_area
```
