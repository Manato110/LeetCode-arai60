## Step.1
他の方のPR、生成AIなどを参考にしながら書いていく  
この問題自体、「島探し」という有名問題らしい  
https://qiita.com/masaya8028/items/7a19c0b086c81e41b5ca  
解法のアイデア  
 - その地点を通ったのかを示す表`visited`を用意,はじめはすべて`False`  
 - 入力のマップを左上から順にみていく  
 - その位置が`1` = 陸地かつ、まだ訪れていない位置なら、その位置から深さ優先探索`dfs`を実行
 - `dfs`関数について
   - 見ている地点が陸地でない、または訪れた陸地がないなら終了
   - その地点から上下左右に移動した地点で再帰的に`dfs`関数を呼び出す
 - 探索が終了したら、島を1つ踏破したことになるので、島のカウント`island_count`を1増やす  

### 書いたコード1  
```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        rows = len(grid)
        cols = len(grid[0])

        visited = [[False] * cols for _ in range(rows)]
        island_count = 0

        for i in range(rows):
            for j in range(cols):
                if grid[i][j] == '1' and not visited[i][j]:
                    self.dfs(i, j)
                    island_count += 1
        
        return island_count

    def dfs(self, x, y):
        if x < 0 or x >= cols or y < 0 or y >= rows or grid[x][y] == '0' or visited[x][y]:
            return
        
        visited[x][y] = True
        dfs(x - 1, y)
        dfs(x + 1, y)
        dfs(x, y - 1)
        dfs(x, y + 1)
```
`Error`発生  
関数の呼び出し部分で`self`をつけていない、  
`dfs`関数内で使用している`rows`, `cols`, `visited`などを引数に設定していないことが原因だった  
修正を加える

```python

```

```python

  return
```

```python
if visited[x][y]:
```

### 書いたコード3
```python
class Solution:
    LAND = '1'
    WATER = '0'

    def numIslands(self, grid: List[List[str]]) -> int:
        rows = len(grid)
        columns = len(grid[0])

        visited = [[False] * columns for _ in range(rows)]
        island_count = 0

        for i in range(rows):
            for j in range(columns):
                if grid[i][j] == self.LAND and not visited[i][j]:
                    self.explore_island(i, j, rows, columns, grid, visited)
                    island_count += 1
        
        return island_count

    def explore_island(self, x, y, rows, columns, grid, visited):
        if not(0 <= x < rows and 0 <= y < columns):
            return
        if grid[x][y] == self.WATER:
            return
        if visited[x][y]:
            return
        
        visited[x][y] = True
        self.explore_island(x - 1, y, rows, columns, grid, visited)
        self.explore_island(x + 1, y, rows, columns, grid, visited)
        self.explore_island(x, y - 1, rows, columns, grid, visited)
        self.explore_island(x, y + 1, rows, columns, grid, visited)
```

コード3を見て気になったのが、再帰呼び出しする関数の引数が多く可読性が低く感じる  
ここの引数を減らしたい ⇒ 関数を内側で設計する  

ということで、やってみる

### 書いたコード4

```python
class Solution:
    LAND = '1'
    WATER = '0'

    def numIslands(self, grid: List[List[str]]) -> int:
        if not grid: 
            return 0

        rows = len(grid)
        columns = len(grid[0])

        visited = [[False] * columns for _ in range(rows)]
        island_count = 0

        def explore_island(x, y):
            if not(0 <= x < rows and 0 <= y < columns):
                return
            if grid[x][y] == self.WATER:
                return
            if visited[x][y]:
                return
            
            visited[x][y] = True

            explore_island(x - 1, y)
            explore_island(x + 1, y)
            explore_island(x, y - 1)
            explore_island(x, y + 1)

        for i in range(rows):
            for j in range(columns):
                if grid[i][j] == self.LAND and not visited[i][j]:
                    explore_island(i, j)
                    island_count += 1
        
        return island_count
```
正直、ここはエンジニアの常識を知らない自分にとって判断ができない  
どちらの方が良いコードといえるのでしょうか？  
個人的には内側に関数を定義しない方が見やすかったのかな...分けた方が理解しやすいように感じました  

入力を`M`行`N`列の`M * N`リストとしたとき、  
時間計算量：`O(M * N)`　探索時すべてのマスを1回だけ訪れるため  
空間計算量：`O(M * N)`　`visited`の確保分、再帰呼び出しによるスタックが最悪の場合`M * N`個積みあがる
