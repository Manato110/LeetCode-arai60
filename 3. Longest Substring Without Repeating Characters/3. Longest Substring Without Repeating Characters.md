## Step.0

問題の理解から  

Given a string s, find the length of the longest substring without duplicate characters.
```python
Example 1:

Input: s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3. Note that "bca" and "cab" are also correct answers.
Example 2:

Input: s = "bbbbb"
Output: 1
Explanation: The answer is "b", with the length of 1.
Example 3:

Input: s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with the length of 3.
Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.
```
Constraints:  

0 <= s.length <= 5 * 104  
s consists of English letters, digits, symbols and spaces.  

入力に対する、連続する部分列のうち、重複する文字がないものの最長の長さを答える  
以前の勉強会で出題された問題と同じ内容かな...?  

扱う文字は英字・数字・記号と空文字、おおよそ合計50文字くらい?  

勉強会を聴講したときに、スライディングウィンドウについて言及があったので、そのアイデアの解法を考えてみる  
考える連続部分列の左端を`left`,右端を`right`とおく  
考えている連続部分列の長さを`length`とおく  
重複の確認のために、登場した文字をKey, その位置をValueとした辞書を用意する  
setだと、重複の文字の位置が分からないので、使用しない  

調べていくのは、右端の文字を軸にして、重複が無いように考える連続部分列  
その長さを求め、これまで考えたものより長いなら更新する  
次のように入力列を順にみていく  
 - `right`を一つ右にずらす、その位置の文字が辞書にないものなら、辞書に登録して終わり
 - その位置の文字が辞書にあるものなら、辞書に登録されているValue(=重複文字のうち、位置が若い方)に1足したものを`left`として更新する
   これによって、重複がないように、`right`を含むような連続部分列で暫定最長のものを考えられる
 - `right - lefr + 1`がその時点での連続部分列の長さ、これで最大値を更新できるか`max`を取って確認

見積もりについて  
時間計算量：`left`, `right`も戻ることなく高々`n = len(S)`だけスライドする、よって`O(n)`、重複の確認は`O(1)`で済むから全体で`O(n)`  
空間計算量：最悪の場合、入力全体に重複がない場合、`n`個の要素が辞書に登録されるから、`O(n)`  

コードに起こす  
### 書いたコード 1  
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        longest_length = 0
        left = 0
        seen_letter_to_index = {}

        for right in range(len(s)):
            right_letter = s[right]
            
            if right_letter in seen_letter_to_index:
                left = seen_letter_to_index[right_letter] + 1
            
            seen_letter_to_index[right_letter] = right            
            longest_length = max(longest_length, right - left + 1)
        
        return longest_length
```

right = 1 ('b'): left = 0, 辞書 {'a': 0, 'b': 1}  　
right = 2 ('b'): 重複があるので、leftをbの位置(1) + 1 = 2 にする。辞書{'a': 0, 'b': 2}  　
right = 3 ('a'): 重複があるので、leftをaの位置(0) + 1 = 1 にする。

外側の重複部分を処理したときに内側の重複部分を考慮することを忘れてしまっている

セットver
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        longest_length = 0
        left = 0
        seen_letter = set()

        for right in range(len(s)):
            while s[right] in seen_letter:
                seen_letter.remove(s[left])
                left += 1

            longest_length = max(longest_length, right - left + 1)
            seen_letter.add(s[right])

        return longest_length
```
