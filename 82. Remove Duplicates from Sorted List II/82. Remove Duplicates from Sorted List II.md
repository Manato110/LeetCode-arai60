```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(-1)
        dummy.next = head
        prev = dummy
        curr = head

        while curr and curr.next:
            if curr.val == curr.next.val: #重複部分があればスキップ
                while curr.next and curr.val == curr.next.val:
                    curr = curr.next
                prev.next = curr.next
            
            else:
                prev = prev.next #重複しない部分はつなげる
            
            curr = curr.next
        
        return dummy.next        
```

開始10分までの間に考えたこと：<br>
リストは昇順ソート済みになっている⇒すでに見たノードの値を記録する必要はない。<br>
重複部分があったらその部分を消去すればよい⇒最低でも連続3つノードを見る必要がある<br>
10分以上考えても答えが思いつかなかったので、geminiにヒントをもらいながら作成しました。<br>

先頭部分で重複があったときのために、新たな先頭ノードとしてダミーノード`dummy`を用意しています。<br>
Acceptされたのでその時のコードを載せているが、15,16行目で似たような内容が重複しているから、簡略化できる...？<br>
以前使用していた変数名`current`,`previous`は何回も書くと無駄に長く見づらいと感じたので、`curr`, `prev`に省略しています。

時間計算量：すべてのノードを見る必要があるため、リストの長さに比例　⇒　O(N)<br>
空間計算量：変数はすべて高々1組の要素しか持たない　⇒　O(1)
