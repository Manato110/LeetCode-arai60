## Step.0

問題の理解から  

Given two strings s and t, return true if s is a subsequence of t, or false otherwise.  
A subsequence of a string is a new string that is formed from the original string by deleting some (can be none) of the characters   
without disturbing the relative positions of the remaining characters. (i.e., "ace" is a subsequence of "abcde" while "aec" is not).

```python
Example 1:
Input: s = "abc", t = "ahbgdc"
Output: true

Example 2:
Input: s = "axc", t = "ahbgdc"
Output: false
 
Constraints:
0 <= s.length <= 100
0 <= t.length <= 10^4
s and t consist only of lowercase English letters.
```

Follow up: Suppose there are lots of incoming s, say s1, s2, ..., sk where k >= 10^9, and you want to check one by one to see if t has its subsequence. 
In this scenario, how would you change your code?  

英語の子文字からなる2つの文字列`s`・`t`が入力される  
`s`が`t`の`subsequence`かを判定する  
つまり、連続していなくても良いので、`t`から要素を取り出していって`s`に一致させることが出来るのかを判定する  

まず間違いなく、`t`から考えうる`subsequence`を列挙して`s`を作れるか？のようにするのは、  
コストが大きすぎるから良い解答とはいえない  
なので、`s`が`t`の`subsequence`かを判定する方向で見ていく  

シンプルにやるなら、`s`の全ての文字を順に存在するのか、`subsequence`の要件を満たすように見ていくことだろう  
文字が`t`の`i`番目に見つかったとしたら、次の文字は`t`の`i + 1`番目から捜査していく、のようにしたら、  
`t`を一巡走査して判定が可能だから、時間計算量`O(n)`でできる  

一旦この方向でやってみる  
探す対象の文字を変えていき、走査を途中から再開、のようなプロセスになっているので、どこまで見たのかという情報を保持したい  
なので、配列のインデックスで操作の状態を持つことにする  

実行に必要なステップとしては、走査する文字の対象は`len(s)`個なので最大`100`個、これを設定するステップと、  
`len(t)`個、つまり最大`10^4`個の文字を見ていくステップがあるので、  
併せて`10100 = 1.01 * 10^4`ステップ  
pythonでは`10^7`ステップ/秒として、`1.01 * 10^-3s = 1.01ms`くらいと見積もる  
空間計算量については、保持したい情報は全て単一の変数なので`O(1)`

実際に書いてみる  
### 書いたコード 1
```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        t_checkpoint = 0
        
        for i in range(len(s)):
            target_string = s[i]
            found = False

            for j in range(t_checkpoint, len(t)):
                if t[j] == target_string:
                    t_checkpoint = j + 1
                    found = True
                    break
            
            if not found:
                return False
        
        return True
```
書いていて、やりたい内容に対してコードがちょっとだけ複雑に感じた  

two pointerの方法を思いついた  
`s`と`t`それぞれ見ている要素のインデックスを保持しておいて、  
順に走査していき、最終的に`s`のインデックスが`len(s)`に等しかったら`True`そうでないなら`False`  

### 書いたコード 2
```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        s_index = 0
        s_length = len(s)

        for t_index in range(len(t)):
            if s_index == s_length:
                return True

            if s[s_index] == t[t_index]:
                s_index += 1

        return s_index == len(s)
```

### 書いたコード 3
```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        s_index = 0
        t_index = 0
        s_length = len(s)
        t_length = len(t)

        while s_index < s_length and t_index < t_length:
            if s[s_index] == t[t_index]:
                s_index += 1
            t_index += 1
        
        return s_index == len(s)
```
個人的に、コード3の方が、やりたい核心部分の処理が分かりやすく、読みやすいと感じた  

Follow upについて  
`s`が複数(`10^9`個以上)渡されるような場合にはどうするか？という内容  

`10^9`回上の走査をおこないのは、さすがに時間がかかりすぎる...  
単純計算で、`0.101ms * 10^9 = 101s`くらい  

毎回の走査で共通しているのは、`t`は同じということ  
なので、`t`をうまい具合に前処理が出来たら、良いのではないか  
ただ、どんなことをしたらよいのか、これ以上は思いつかなかった
