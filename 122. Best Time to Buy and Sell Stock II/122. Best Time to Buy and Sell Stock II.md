## Step.0
まずは自力で解く  
問題の理解からおこなう  

前問の派生版で、株の売り買いを何回でも行えるので、その中で最終的な利益が最大となる場合を考える。  
今回も入力は空でないことが保証されている  

最初に思ったのは、より値段が安い株を見たら安い方に乗り換え、  
保持している株の値段より高い株価になったら売るを繰り返す方法  

現実だったら、安い方にノーリスクで乗り換えなんてできるわけがないが、  
一旦割り切ってこれで行けるか考える  

この方法でうまくいかない場合を考える、  
保持している株の値段より高い株価を見つけたら、すぐに売って大丈夫なのかの確認  

が、すぐに売るのと、さらに高いときに売るので違いはないという結論になった  
例えば、`prices = [1, 2, 3]`で、`1`を保持して`3`で売るのと、  
`1`保持⇒`2`で売り`2`で買う⇒`3`で売る  
で総額利益はどちらも`2`である  

見積もり  
 - 買う株の判断部分について、比較、変更で2ステップ
 - 売るときの判断部分について、比較、利益算出、合計収益への合算、保持する株の更新で4ステップ

平均して3ステップ、これを入力の長さ分おこなうとして、
最大で3 * 10^4なので、合計9 * 10^4ステップ  
pythonでは、10^7ステップ/ 秒とすると、  
9 * 10^4 / 10^7 = 9msくらいか  
オーダーで`O(N)`だし、悪くはない  
空間計算量についても、保持するのは全て一時変数になるから、`O(1)`  

とりあえず、大丈夫だろうということでコードを書いてみる  

### 書いたコード 1
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        buy_price = float('inf')
        total_profit = 0

        for price in prices:
            if buy_price > price:
                buy_price = price

            elif buy_price < price:
                profit = price - buy_price
                total_profit += profit
                buy_price = price
        
        return total_profit
```

## Step.1
他の方々のPRを見て修正していく  

https://github.com/hiro111208/leetcode/pull/26  
`max`関数を用いてコードを短くしている  
毎回関数を呼び出しているから、実行時間はコード1の方が短いだろう  
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if len(prices) < 2:
            return 0
        max_profit = 0
        for i in range(1, len(prices)):
            max_profit += max(prices[i] - prices[i - 1], 0)
        return max_profit
```

https://github.com/attractal/leetcode/pull/27  
tabulationタイプのDPによる解法を行っていた  
株を持っている状態、持っていない状態の2状態の場合をそれぞれ更新していく  
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        before_buy = 0          # 何も持ってない状態
        holding = float('-inf') # 株を持ってる状態

        for price in prices:
            new_before_buy = max(before_buy, holding + price)  # 何もしない or 売る
            new_holding = max(holding, before_buy - price)     # 何もしない or 買う

            before_buy = new_before_buy
            holding = new_holding

        return before_buy
```
これは面白い  
PR内でも記載されていたが、応用が効きそうな解法だなと感じた  
例えば、類題Best Time to Buy and Sell Stock IIIでは購入回数に制限が設けられているらしい  
DPなら、購入回数についても値を保持しながら遷移することを行えばできそう
