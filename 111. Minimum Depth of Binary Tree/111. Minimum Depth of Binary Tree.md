## Step.0
まずは自力で解く  
前問が葉の深さの最大値を答えるのに対して、今度は最小値を考える  

大きく変わるのは、葉を全て見なくてもよいケースがあるということ  
例えば、今見ている葉が暫定の深さ最小値`m`だとして、  
残りの葉の深さが`m`以上(残りのノードにはまだ葉がある)ことが分かれば、  
その時点で最小値`m`が確定する  

深さを小さいところから見たいから、BFSに軍配が上がりそうか  
DFSだとまだ見ていない葉が最小値である可能性を排除しきれず、結局すべての葉を見る必要があり、早期終了できない  

見ているノードが葉である(子がいない)ことが分かったら、その時の深さを返せばOK  

前問と解いてから日が浅いのもあり、2,3分でコードが出来上がった  

### 書いたコード
```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        depth = 0
        same_depth_nodes = deque([root])
        
        while same_depth_nodes:
            depth += 1
            for _ in range(len(same_depth_nodes)):
                node = same_depth_nodes.popleft()

                if not node.left and not node.right:
                    return depth
                if node.left:
                    same_depth_nodes.append(node.left)
                if node.right:
                    same_depth_nodes.append(node.right)
        
        return depth
```
`AC`  
時間計算量：`O(N)`最悪の場合、  
例えば、木が左に偏っている状況`root = [1, 2, null, 3, null, 4, null ...]`のような場合、すべてのノードを見る必要がある  

空間計算量：葉の深さが最小となる深さにおけるノードの個数(木の幅)が最大となるところに依存するので、これを`W`とおくと`O(W)`

### 書いたコード2
```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        depth = 0
        nodes_and_depth = deque([(root, 1)])
        
        while nodes_and_depth:
            node, depth = nodes_and_depth.popleft()

            if not node.left and not node.right:
                return depth
            if node.left:
                nodes_and_depth.append((node.left, depth + 1))
            if node.right:
                nodes_and_depth.append((node.right, depth + 1))

        raise ValueError("Invalid binary tree (No leaf node was found)")
```

### 書いたコード 3
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        if root.left is None and root.right is None:
            return 1
        
        if root.left is None:
            return self.minDepth(root.right) + 1
            
        if root.right is None:
            return self.minDepth(root.left) + 1
        
        return min(self.minDepth(root.left), self.minDepth(root.right)) + 1
```
