## Step.0
まずは自力で解く  
問題の理解から  

`n`円硬貨のリスト`coins`を、ターゲット金額`amount`が渡されて、  
`amount`を`coins`の硬貨で、最小枚数で表現できるときに、その枚数を答える問題  

なるべく使用する枚数を減らしたいなら、値段の高い硬貨を優先的に使用したい  
が、愚直にそうすると、うまく求められないケースが出てくる  
例えば、  coins = [2,5], amount = 11の時は、2を3枚、5を1枚使った4枚が答えで、  
5を2枚使ったら合計を11にすることは不可能になり、不適  

一番最初に思いついたのは、tabulationのDPで解く方法  
`0`円から`amount`円まで、`coins`で換算できるなら最小何枚で表せるかというリスト`checklist`を作成  
初め、`checklist = float('inf')`で初期化しておく  

(問題では、換算不可を`-1`で表現しているが、`-1`で初期化する場合、  
最小枚数を更新するときに、`min`関数を使うと、`-1`になってしまって、不都合)  

`coins`に入っている値`coin`は、1枚で表現できるから、そこは先に`checklist[coin] = 1`を入れておく  
for文で、`0`から`amount`円まで見ていく  
 - `checklist[index] != float('inf')`のとき、
   - `coins`にある`coin`硬貨を一つずつ見て、
   - `checklist[index + coin]`、つまり、`coin`円だけ先の最小枚数が更新可能なら更新していく

これを`amount`円までおこなって、最後に`checklist[amount]`が有限の値なら、それを出力する  
`float('inf')`なら`-1`を出力する  

最悪の場合で考えると、全ての値の場合で`coins`の要素分更新できるか比較する必要がある、  
依って、n = len(coins), m = amountとすると、  
時間計算量は`O(nm)`  
空間計算量は、保持するのは`checklist`のみなので、`O(m)`  
制約で、 `1 <= n <= 12`, `1 <= m <= 10^4`なので、  
時間計算量は、nm = 12 * 10^4 ステップ = 12msのオーダーで増えていく  
空間計算量、つまり使用メモリは、最大で28 byte * 10^4 / 1024 = 280KB  

この時に気づいたけど、硬貨の最大金額が`2^31 - 1`円だったのか  

コードに起こしてみる  

### 書いたコード 1
```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        if amount == 0:
            return 0

        checklist = [float('inf')] * (amount + 1)
        for coin in coins:
            if coin <= amount:
                checklist[coin] = 1
        
        for index in range(amount + 1):
            if checklist[index] != float('inf'):
                for coin in coins:
                    if index + coin <= amount:
                        if checklist[index + coin] > checklist[index] + 1:
                            checklist[index + coin] = checklist[index] + 1
        
        if checklist[amount] == float('inf'):
            return -1
        else:
            return checklist[amount]
```

```python
import functools


class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:

        @functools.cache
        def calc_minimum_num_coins(amount: int) -> int:
            if amount == 0:
                return 0

            # 「(総額 - コインの額)を作るのに必要な最小枚数」+ 1 の最小値を計算
            minimum_num_coins = float("inf")
            for coin in coins:
                num_coins = calc_minimum_num_coins(amount - coin)
                if num_coins == -1:
                    continue
                minimum_num_coins = min(minimum_num_coins, num_coins + 1)
            
            # float("inf")は特殊な値なので, ==の比較が正しく動作する
            # IEEE754 - https://tmytokai.github.io/open-ed/activity/fpoint/text03/page02.html
            if minimum_num_coins == float("inf"):
                return -1
            return minimum_num_coins

        return calc_minimum_num_coins(amount)
```
