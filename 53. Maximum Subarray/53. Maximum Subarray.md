## Step.0
まずは自力で解く  

問題の理解から  
入力の連続部分列のうち、総和が最大なものの値を出力する  
入力の長さは1以上10^5以下、空列が入力されることはない  

Subsequence：部分列  
Subarray：連続部分列  

最初に思いついたアイデア  
 - `i`番目までの累積和を`total_table`として保持    
 - `i`番目から`j`番目までの要素からなる連続部分列は`total_table[j] - total_table[i]`と表せることを用いる
 - `i`、`j`の二重ループで調べ上げて、暫定値よりも大きかったら更新することをくりかえす

連続部分列の左端、右端という意味で、`i`を`left`、`j`を`right`と命名  

`for`の二重ループになるので、`O(N^2)`の時間計算量  
保持するのは、累積和のテーブルなので、入力の要素数に比例し、`O(N)`の空間計算量  

制約で、入力リストの要素数は最大で10^5、  
そのため、pythonの実行ステップが10^7回/秒として、  
10^10 / 10^7 = 10^3sのオーダーで増加する  
これでは`TLE`になってしまうだろう

ここで気づいたことが、総和が最大となってほしいのだから、

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        prefix_sum = 0
        min_prefix_sum = 0
        max_subarray_sum = float('-inf')

        for num in nums:
            prefix_sum += num
            max_subarray_sum = max(max_subarray_sum, prefix_sum - min_prefix_sum)
            min_prefix_sum = min(min_prefix_sum, prefix_sum)
        
        return max_subarray_sum

### 考え方  
 - DP[i]をAにおけるi以下の任意の要素(A[0]...A[i-1])から  
 - 要素i(A[i])までの部分配列における和の最大値と定義する。  
   (最初の要素から要素iまでの最大値ではないことに注意)
 - すると初期状態と状態遷移は下記のようになる。

 - 初期状態：DP[0] = A[0]  
 - 状態遷移：DP[i+1] = max(A[i+1], DP[i]+A[i+1])  
   (意味：DP[i+1]はA[i+1]もしくはDP[i]にA[i+1]を足したもの)  
 - このときDP[n-1]が答えになるわけでなく、DP[0]...DP[n-1]の中での最大値が答えとなる。  

コードを書く  
暫定的な最大値を保持するということで、変数名に`temporary`をつけている  
使用する意味的には、`interim: 正式決定までの一時的・暫定的な状態`の方が適切な気がするが、  
日本人には`temporary`の方がなじみがあると思ったので、こちらを採用している  

### 書いたコード 3
```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_subarray_sum = float('-inf')
        temporary_max_subarray_sum = 0

        for num in nums:
            temporary_max_subarray_sum = max(temporary_max_subarray_sum + num, num)
            max_subarray_sum = max(max_subarray_sum, temporary_max_subarray_sum)
        
        return max_subarray_sum
```

要約すると、問題を小さな部分問題に分割（Divide）し、  
各部分問題を再帰的に解いて（Conquer）、  
最後にそれらの解を統合（Combine）して全体の解を得る方法  

動的計画法と異なるのは、分割問題に重複部分がないこと  
よく使われるのは、マージソートやクイックソート  

例えば今回であれば、  
目標となる総和が最大となる連続部分列が、  
入力の左側・右側・左右にまたがっているかの3つに再帰的に分割して、求めていく  
3つの区間それぞれで計算したら、それをまとめていく  

### 書いたコード 4
```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        return self.max_subarray_sum_in_range(nums, 0, len(nums) - 1)
    
    def max_subarray_sum_in_range(self, nums, left, right) -> int:
        if left == right:
            return nums[left]
        
        def max_subarray_sum_through_middle(nums, left, right, middle) -> int:
            leftward_max_sum = float("-inf")
            leftward_sum = 0
            for i in range(middle, left - 1, -1):
                leftward_sum += nums[i]
                leftward_max_sum = max(leftward_max_sum, leftward_sum)
            
            rightward_max_sum = float("-inf")
            rightward_sum = 0
            for i in range(middle + 1, right + 1, 1):
                rightward_sum += nums[i]
                rightward_max_sum = max(rightward_max_sum, rightward_sum)
            
            return leftward_max_sum + rightward_max_sum
        
        middle = (left + right) // 2
        left_max_subarray_sum = self.max_subarray_sum_in_range(nums, left, middle)
        right_max_subarray_sum = self.max_subarray_sum_in_range(nums, middle + 1, right)
        middle_through_max_subarray_sum = max_subarray_sum_through_middle(nums, left, right, middle)

        return max(
            left_max_subarray_sum,
            right_max_subarray_sum,
            middle_through_max_subarray_sum
        )
```
