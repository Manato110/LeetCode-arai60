## Step.0
まずは自力で解く  

二分木の深さを出力すればオーケー  
全ての葉を見ていって、深さの最大値を適宜更新していく感じで良さそう  

入力が根に近い順に並んでいる　⇒　幅優先探索的に根に近いところから見ていけば良さそう  
深さ`i`のところの葉をスタックに入れていく  
最後にスタックがすべて空になっていたら、その時の深さを出力  

...と思ったが、今回リストに入れていくノードを、入れた順に取り出してみていきたいからFIFOか  
意図としては、どの深さを見るときも、左側から右側の順にみていくようにしたいため  

ならスタックよりキューといった方が誤解がない  

### 書いたコード1
```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        depth = 0
        queue = deque([root])

        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            depth += 1
        
        return depth
```
`AC`  
時間計算量:すべての葉を見ているので、入力リストの長さに比例⇒`O(N)`
空間計算量:キューに入れるの葉の量は、ある深さにおける葉の個数が最大のところ、これを`L`とでも置くと、`O(L)` 　
解くのに大体10分くらいかかった

葉から見て、自分と子の木の高さ(左右どちらかの高さの最大値)を返す

### 書いたコード2
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)

        return max(left_depth, right_depth) + 1
```

BFS, DFSの両方を行ったが、どちらにも利点があり、  
どちらが好ましいかは対象となる二分木の形にもよる  

BFS：木が大きい・縦に長い(深さが大きい)場合でも問題なく使える  
DFS：コードが読みやすい、木があまり大きくない・縦に長くないのならこっちの方が良い
