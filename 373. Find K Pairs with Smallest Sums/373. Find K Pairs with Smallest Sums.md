## Step.0  
まずは問題の理解から  
数字のペアで和が小さい順にk個出力する  
アイデアとして思いついたのは2つ  
1. ペアをすべて列挙したリストをまとめ、和が小さい順にソートした後に前からk個出力
2. heapを使って、和が最小となるペアをk個保持しながら順に調べ、最終的に残ったk個を出力（自信ないけどできそう）  
&nbsp;

heapにまだ慣れていないのもあり、最初に思いついた素朴な案1を始めに実装してみる  
最近習得したlambda式を使って、和が小さい順ソートを行っています  
### 書いたコード1
```python
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        pairs = []

        for u in nums1:
            for v in nums2:
                pairs.append([u, v])
        
        pairs.sort(key = lambda x : x[0] + x[1])

        return pairs[:k]
```
見た目は分かりやすい方だと思うが、下からk個出力すれば十分なのにすべてのペアを列挙しているのが明らかにムダ  
少し考えて、`nums1`, `nums2`でそれぞれからk個の要素だけでペアを考えれば十分ということに気づく  
( 例えば、`nums1 = [1, 2, 3, 10]`, `nums2 = [4, 5, 6, 20]`, `k = 3`のとき、  
  `nums1`, `nums2`の先頭から4番目以降の要素は和が`k = 3`番目より小さいところに来ることはない  
  最低でも`k + 1`番目となってしまう)  
&nbsp;  
そこで、ペアにする要素を小さい方からk個ずつ取り出すように修正  
### 書いたコード2

```python
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        num1_limit = min(len(nums1), k)
        num2_limit = min(len(nums2), k)

        pairs = []

        for u in nums1[:num1_limit]:
            for v in nums2[:num2_limit]:
                pairs.append([u, v])
        
        pairs.sort(key = lambda x: x[0] + x[1])

        return pairs[:k]
```
これで空間計算量を`O(k^2)`にすることが出来た  
時間計算量は,  
  ペアの作成の2重ループで`O(k^2)`  
  ペアのソートで`O(k^2logk^2)` = `O(k^2logk)`
なので、全体としては`O(k^2logk)`  
&nbsp;   
テストケースでは通ったが、緑のsubmitでほかのテストケースで検証すると、メモリ不足&時間超過でエラーになっていた  
`O(k^2)`でも、`k`が巨大だと難しいという事だろう  
競プロでもよくやってしまうが、とりあえず答えさえ合っていればいいやとするのはしない方が良いですね

## Step.1
次に、heapを使ってみる  
先ほどのコードよりもムダなく、最小限で列挙、ソートを済ませたい  
せっかく`nums1`, `nums2`が広義の単調増加数列のリストなら、その特性を活用したい...  
けど、どうすればよいのかわからず  
そもそも`nums1`, `nums2`が要素を`k`個持っていないときも考えられ、  
ほぼすべてのパターン列挙する必要がある場合もあると考えると、改善の仕方が思いつかない  
(例えば、`nums1=[1,2,3]`, `nums2=[3,4,5]`, `k=8`)  
他の方のコードや生成AIを参考にコードを書くことに  
&nbsp;  
まず、Step.0で述べたように、`nums1`,`nums2`の長さがkより大きいなら、長さkになるように取り出したもので考えても大丈夫  
よって、この時点で考える`nums1`,`nums2`の長さは最大でも`k`  
そのうえで、まず`nums1[0:k]`と`nums2[0]`でk個の暫定ペアを作り`pairs`にheappush  
その後、`nums2`の要素を順にみていき、新たなペアについて、`pairs`に格納したペアよりも和が小さいかを調べる  
このとき、`nums1[i]`と`nums2[j]`のペアを見るとき、比較する必要があるのは、`nums2`で一つとなりの要素を採用した`nums1[i]`と`nums2[j+1]`
より小さい方を出力するリストに追加していき、長さがk個になったら終了  
### 書いたコード3
```python
class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        pairs = []

        for i in range(min(len(nums1), k)):
            heapq.heappush(pairs, (nums1[i] + nums2[0], i, 0))
        
        ans = []

        while pairs and len(ans) < k:
            s, i, j = heapq.heappop(pairs)
            ans.append([nums1[i], nums2[j]])

            if j + 1 < len(nums2):　
                heapq.heappush(pairs, (nums1[i] + nums2[j + 1], i, j + 1)) #一つ右のnums2要素を採用した場合を入れる 
                
        return ans
```
時間計算量：要素k個のheapでheappop, heappushにかかるのは`logk`,whileでこれをk回行うから、`O(klogk)`  
空間計算量：ペアをk個保持するので、`O(k)`
