## Step.0

問題の理解から  

Description  
Given an integer array nums of unique elements, return all possible subsets (the power set).   
The solution set must not contain duplicate subsets. Return the solution in any order.

 ```python
Example 1:
Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

Example 2:
Input: nums = [0]
Output: [[],[0]]
 

Constraints:
1 <= nums.length <= 10
-10 <= nums[i] <= 10
All the numbers of nums are unique.
 ```
要素の重複のない入力リスト`nums`の要素から、  
考えられるすべての部分集合をまとめたリストを出力する  

`n = nums.length`として、一要素を部分集合に含めるか否かの2通りをn個の要素すべてでおこなうので、  
できる部分集合は合計`2^n`個  
なので最大`2^10 = 1024`個、個数自体はそんなに大きくない  
雰囲気は前問(permutation)に似ている  

全ての要素について、順に、部分集合に入れる場合と入れない場合を検討することを行いたい  
再帰か、DFS、BFSでできそう  

再帰はすぐにコードが思いつか那そうだったので、DFS、BFSで検討  
実行する処理の回数は同じだから、時間計算量は同じだろう  
時間計算量について、作成される部分集合の個数`2^n`分処理を行っている、  
特に出力するリストへの保存に`O(n)`かかるから、合計`O(n * 2^n)`  

使用するメモリについて、今回のように、要素が入るか否かによる樹形図を書こうとしたら、  
樹形図の形状は横に広いものになる  

使用するメモリについて、DFSは樹形図の深さだけスタックに積まれるので、最大でも`n`個 = `O(n)`  
BFSでは樹形図の広さだけ積まれるので、最大`2^n`個 = `O(2^n)`  
今回はDFSの方が空間計算量の観点で良いといえる  

DFSで書いてみる  
要素数が少ない順に最終的に出力してほしいと思ったため、stackには  
今までの集合に新たに要素を追加しない場合 -> 追加する場合の順で検討し積み込む  

### 書いたコード1 (DFS)
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        subsets = []
        candidates = [(0, [])]

        while candidates:
            index, partial_subset = candidates.pop()    
            if index == len(nums):
                subsets.append(partial_subset)
                continue

            candidates.append((index + 1, partial_subset + [nums[index]]))
            candidates.append((index + 1, partial_subset))
        
        return subsets
```

### 書いたコード2 (BFS)
```python
from collections import deque


class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        subsets = []
        candidates = deque([(0, [])])

        while candidates:
            index, partial_subset = candidates.popleft()    
            if index == len(nums):
                subsets.append(partial_subset)
                continue

            candidates.append((index + 1, partial_subset))
            candidates.append((index + 1, partial_subset + [nums[index]]))
        
        return subsets
```

### 書いたコード3 (recursion)
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        subsets = []
        
        def subsets_helper(index: int, partial_subset: List[int]) -> List[int]:
            if index == len(nums):
                subsets.append(partial_subset)
                return
            
            subsets_helper(index + 1, partial_subset)
            subsets_helper(index + 1, partial_subset + [nums[index]])

        subsets_helper(0, [])
        return subsets
```

ビットマスクを利用した解法  
> n個の要素それぞれに「含める（1）/ 含めない（0）」のbitを割り当てる。  
> 0から2^n - 1までの整数をbit列として解釈すれば、全2^n通りの組み合わせを列挙できる

確かに、含める・含めないということと1・0のビットで表現することに共通するところは多い  
この発想はアイデアの一つとして覚えておこう  

```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        n = len(nums)
        result = []
        # 0 ~ 2^n - 1
        for mask in range(1 << n):
            subset = []
            for i in range(n):
                # i桁目が1である
                if mask >> i & 1:
                    subset.append(nums[i])
            result.append(subset)

        return result
```

### 書いたコード 4 (backtracking)
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        subsets = []
        partial_subset = []
        
        def backtrack(index: int) -> None:
            if index == len(nums):
                subsets.append(partial_subset[:])
                return
            
            partial_subset.append(nums[index])
            backtrack(index + 1)
            partial_subset.pop()
            backtrack(index + 1)

        backtrack(0)
        return subsets
```
