## Step.0
まずは自力で解く  

入力の木が、BST(二分探索木)なのか判定する  
最悪の場合、全てのノードを見ないといけない  
その場合、一つのノードのチェックに5～10実行ステップ必要とすると、  
ノード数は最大で10000なので、pythonで1秒当たり10^7回実行ステップとすると、  
`10000 × 10 / 10^7 = 10^-2`、`5～10ms`くらいかかると予想  

使用メモリは、一つの数値に28bytes必要なので、  
最大で`28bytes × 10000 = 280000 bytes ≈ 280KB`

解法を考える  
すぐに思いついたのは、再帰で解く方法  
反復でもBFS・DFS両方できるね  

有効であることの判断は、ノードが指定の範囲内の値を持っていること  
下界を`left`、上界を`right`として再帰的に見ていってみよう  
再帰が最も良い方法とは思っていないが、一番最初に思いついたので実装する  

気がかりなのが、`left`と`right`の初期値の問題  
今回、ノードの値がすべて整数、つまり`int`型なのに、無限大は`float('inf')`で`float`型である  
他の方も感じていたところで、`int`と`float`の比較に見えるのが違和感  
今回みたいにノードの値の最小・最大が分かっているなら、それをもとに調整してよいのだろうか...  
例えば、今回では制約が`-2**31 <= Node.val <= 2**31 - 1`なので、`left=-2**31-1`、`right=2**31`でもok   

一旦、どのような値を取るのかわからないという想定で、`float('inf')`を採用して書く  

### 書いたコード 1
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:

        def is_Valid_BST(node, left, right):
            if node is None:
                return True

            if not (left < node.val < right):
                return False
            
            return is_Valid_BST(node.left, left, node.val) and is_Valid_BST(node.right, node.val, right)

        return is_Valid_BST(root, float('-inf'), float('inf'))
```
`AC`
最悪の場合の計算時間は、全てのノードの探索で`O(N)`  
空間計算量も、全てのノードを探索するために`O(N)`  

反復でも書いてみる  
BFSの方がイメージしやすかったので、先にBFSで  

変数の修正：`left`, `right`より、範囲の下限・上限という意味で`lower`, `upper`の方が伝わりやすいか  

### 書いたコード 2
```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        if root is None:
            return True
        
        lower = float('-inf')
        upper = float('inf')
        node_and_ranges = deque([(root, lower, upper)])

        while node_and_ranges:
            node, lower, upper = node_and_ranges.popleft()
            if not (lower < node.val < upper):
                return False
            
            if node.left is not None:
                node_and_ranges.append((node.left, lower, node.val))
            if node.right is not None:
                node_and_ranges.append((node.right, node.val, upper))
        
        return True
```

### 書いたコード 4
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        if root is None:
            return True
        
        frontier = []
        node = root
        lower = float('-inf')

        while frontier or node:
            while node is not None:
                frontier.append(node)
                node = node.left
            
            node = frontier.pop()
            if not node.val > lower:
                return False
            
            lower = node.val
            node = node.right
        
        return True
```
