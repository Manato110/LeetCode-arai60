```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(-1)
        ans = dummy
        carry = 0 # 繰り上がりの値保持

        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0

            total = val1 + val2 + carry
            digit = total % 10　#各桁の値の計算
            carry = total // 10　#繰り上がりの計算
            ans.next = ListNode(digit)

            ans = ans.next

            #次の位の値を格納、ないならnull
            l1 = l1.next if l1 else None
            l2 = l2.next if l2 else None 
        
        return dummy.next
```

感想

加算をおこなうということで、CPUの加算器のアーキテクチャを思い出しながら解きました。

アイデア <br>
各桁ごとに加算し、位の数`digit`, 繰り上がり`carry`を算出 <br>
`l1`,`l2`で桁が異なる場合、最上位で繰り上がりがあることを考慮して、最上位に到達したら`null`を入れる。 

位の数の変数名として、和を取っているので`sum`にすることが多いと思うのですが、<br>pythonのsum関数と同じ名前にすると混乱を招く(やっていることは同じだが)可能性があるので、<br>別の名として`digit`としています。

時間計算量 O(N)：桁の長さだけwhileループするため、リストの長さに比例<br>
空間計算量 O(1)：使用する変数`val1`,`val2`,`total`, `digit`, `carry`はすべて一時的な変数である
