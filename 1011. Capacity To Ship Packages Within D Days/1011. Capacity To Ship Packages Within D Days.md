## Step.0
まずは自力で解く  
問題の理解から  

A conveyor belt has packages that must be shipped from one port to another within days days.

The ith package on the conveyor belt has a weight of weights[i]. Each day, we load the ship with packages on the conveyor belt (in the order given by weights). We may not load more weight than the maximum weight capacity of the ship.

Return the least weight capacity of the ship that will result in all the packages on the conveyor belt being shipped within days days.

順番が決まっている荷物たち`weights`を、`days`日で運搬することを考える  
一日に運搬できる容量が固定であるとするとき、その値の最小値を求める  

制約  
```
1 <= days <= weights.length <= 5 * 10^4
1 <= weights[i] <= 500  
```
似たような雰囲気の問題を以前AtCoderでトライしたことがあるので、その時の知見が使えそう  

容量の最小値を求めようとするのではなくて、「その容量なら問題の条件を満たすか？」を判定する問題に置き換える  
その時、求める値は、判定がTrueになる最小の値になるといえる  

考えられる容量で、最大となるのは`weights`の総和に等しいとき(=1日で全て運搬できる)  
最小となるのは、`max(weights)`に等しいとき(=最大`len(weights)`日で全てを運搬できる)  
これを数直線上の右端・左端として、判定を考えていくと、  
左端から求める容量より1小さいところまでは`False`、求める容量から右端までは`True`となる  

制約から、右端で必ず`True`になることは分かっている  
なので、`while`文で、  
中央の容量`middle_capacity`の場合を考えて、  

 - `middle_capacity`で判定が`False`の時は、求める値は`middle_capacity`より大きいということ  
    よって、左端を`middle_capacity + 1`と範囲を絞る  
 - 逆に`middle`で判定が`True`の時は、求める値は`middle_capacity`と同じか、それより小さい可能性があることが分かる  
   よって、右端を`middle_capacity`と範囲を絞る  

これによって、範囲を半分にしながら探索することが出来ている  
`n:sum(weights)`として、`O(logn)`で求めることが出来る  

判定の仕方について  
運搬に必要な最小の日数カウント`days_count`とおく  
暫定の和を`day_weight_sum`としておく
`weights`の要素を前から足していって、  
容量に上回りそうなら`days_count`をインクリメントし、`day_weight_sum`を0にリセット  
これを繰り返して、`days_count`が`days`以下なら判定は`True`、そうでないなら`False`判定  
この判定は`m:len(weights)`として、`O(m)`  

よって、全体の時間計算量は、`O(mlogn)`になる  
`m`は最大で`5 * 10^4`、`n`は最大で`5 * 10^4 * 500 = 25 * 10^6`なので、  
`mlogn = 1.23 * 10^6`なので、  
pythonで実行速度が`10^7`ステップ/秒なので、  
`0.123s = 123ms`のオーダーの時間がかかる  
今まで書いたコードの中では、かなり大きい方だが、十分実行できる  

空間計算量は、保持する値が全て入力の長さ・要素の大きさに依存しないので、`O(1)`  

コードに起こす  
### 書いたコード1
```python
class Solution:
    def shipWithinDays(self, weights: List[int], days: int) -> int:
        left_capacity = max(weights)
        right_capacity = sum(weights)
        
        while left_capacity < right_capacity:
            middle_capacity = (left_capacity + right_capacity) // 2

            day_count = 1
            day_weights_sum = 0
            for weight in weights:
                if day_weights_sum + weight > middle_capacity:
                    day_count += 1
                    day_weights_sum = 0
                day_weights_sum += weight

            if day_count <= days:
                right_capacity = middle_capacity
            else:
                left_capacity = middle_capacity + 1

        return left_capacity
```

```python
class Solution:
    def shipWithinDays(self, weights: List[int], days: int) -> int:
        min_capacity = max(weights)
        max_capacity = sum(weights)

        while min_capacity < max_capacity:
            middle_capacity = (min_capacity + max_capacity) // 2
            
            if self._is_shippable(middle_capacity, weights, days):
                max_capacity = middle_capacity
            else:
                min_capacity = middle_capacity + 1
        
        return min_capacity
    
    def _is_shippable(self, capacity: int, weights: List[int], days: int) -> bool:
        day_weights_sum = 0
        day_count = 1

        for weight in weights:
            if day_weights_sum + weight > capacity:
                day_weights_sum = 0
                day_count += 1
                if day_count > days:
                    return False
            day_weights_sum += weight

        return True
```
