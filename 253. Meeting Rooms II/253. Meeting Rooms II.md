Given an array of meeting time interval objects consisting of start and end times [[start_1,end_1],[start_2,end_2],...] (start_i < end_i),  
find the minimum number of rooms required to schedule all meetings without any conflicts.  
Note: (0,8),(8,10) is NOT considered a conflict at 8.

NeetCode Hint2  
> We create two arrays, start and end, containing the start and end times of all meetings, respectively.   
> After sorting both arrays, we use a two-pointer based approach. How do you implement this?  

`start`・`end`それぞれで配列を作ってあげる  
つまり、"どの会議が"始まった・終わったかという部分は見ずに、  
どこかしらの会議が始まった・終わったというところに注目する  
これなら、会議数`num_in_meeting`は、時系列順に2つの配列を見ていき、`start`が来たら+1、`end`が来たら-1としたら求まる  
`num_in_meeting`の最大値を求めたら終了  

`start`・`end`のペアで、どの開始時間の会議が終わったのかといった、  
今回ほしい出力を求めるうえでは使わない情報に思考が引っ張られてしまっていたのが思いつけなかった原因  

これなら、最初に`start`・`end`のソートに`sorted`関数を使えば`O(nlogn)`、会議数を求めるのに`O(n)`で済む  
実行時間は、`n`が最大500として、  
`2 * 500 * log(500) + 2 * 500 ≒ 5500`ステップ、  
pythonでは`10^7`ステップ/sとしたら、`0.55ms`くらいの見積もり  
メモリを使用するのは、`start`・`end`それぞれをまとめる配列(`O(n)`)と、`num_in_meeting`などの変数(`O(1)`)  

コードに起こしてみる  
### 書いたコード 1
```python
"""
Definition of Interval:
class Interval(object):
    def __init__(self, start, end):
        self.start = start
        self.end = end
"""

class Solution:
    def minMeetingRooms(self, intervals: List[Interval]) -> int:
        start_times = []
        end_times = []

        for interval in intervals:
            start_times.append(interval.start)
            end_times.append(interval.end)

        start_times.sort()
        end_times.sort()

        max_num_in_meeting = 0
        num_in_meeting = 0
        end_index = 0
        for start_index in range(len(start_times)):
            while end_index < len(end_times) and end_times[end_index] <= start_times[start_index]:
                num_in_meeting -= 1
                end_index += 1
            num_in_meeting += 1
            max_num_in_meeting = max(max_num_in_meeting, num_in_meeting)
        
        return max_num_in_meeting
```

AtCoderなど、プログラミングコンテストではよく使う手法らしい  
主に、値の大小による順序関係が重要となる場合に、前処理として使うことで登場する値を小さくできる  
必須のテクニックという訳ではないが、使うと良いときがある...くらいの温度感と感じた  

heapによる解法  
発想としては、なるべく少ない部屋数で回していくが、どうしても足りない場合に新たに部屋を開放して使うような感じ  
使用中の各会議室の仕様衆力時刻について、min-heapで保持する  
最終的なheapのサイズが、求める必要最小限の部屋数となる  

あまりheapに慣れていないので、勉強になった  
なんとなく、今回の会議室という設定を再現しているように感じ、イメージしやすかったと思う
```python
import heapq


class Solution:
    def minMeetingRooms(self, intervals: list[Interval]) -> int:
        if not intervals:
            return 0

        sorted_intervals = sorted(intervals, key=lambda interval : interval.start)

        release_times = []
        for interval in sorted_intervals:
            if release_times and release_times[0] <= interval.start:
                heapq.heapreplace(release_times, interval.end)
            else:
                heapq.heappush(release_times, interval.end)
        
        return len(release_times)
```
