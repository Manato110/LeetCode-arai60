## Step.0
まずは自力で解く  

問題の内容を理解する  
`m × n`のgrid上で、スタート地点が一番左上、ゴールが一番右下のとき、ゴールまでのルートの個数を求める  

まんま高校数学でやったCombinationの問題である  
多分、求める式を出すのが難しいんじゃなくて、それを実装するのが難しいのかな  
Combinationは、mathライブラリのcomb関数を使えば一発だけど、それを使わないなら、確かに悩む  

`m × n`のgridであるなら、下に`(m - 1)`回、右に`(n - 1)`回移動すればよいので、求める組み合わせの個数は、  
`(m + n - 2) C (m - 1)`　(または`(m + n - 2) C (n - 1)`)  

とりあえず、最近comb関数を使ったこともあって、使い方を知っているから、comb関数有のものを書く  

### 書いたコード 1
```python
import math


class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        down_move = m - 1
        right_move = n - 1
        total_move = down_move + right_move

        return math.comb(total_move, down_move)
```
2分もかからなかった  

comb関数を使わない場合を考える  
`(m + n - 2) C (m - 1) = (m + n - 2)! / (m - 1)!(n - 1)!`であるから、 
`(m + n - 2) > (m - 1), (n - 1)`であることを考慮すると、  
`(m + n - 2)!`を求めるまでの累乗を全てメモして、  
最後に`(m + n - 2)! // (m - 1)!(n - 1)!`を計算・出力すればよい  
(combinationは整数値であることが証明できるので、割り算は`//`で)  

### 書いたコード 2
```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        down_move = m - 1
        right_move = n - 1
        total_move = down_move + right_move

        pow_table = [0] * (total_move + 1)
        for i in range(total_move + 1):
            if i == 0:
                pow_table[i] = 1
            elif i == 1:
                pow_table[i] = 1
            else:
                pow_table[i] = pow_table[i - 1] * i
        
        return pow_table[total_move] // (pow_table[down_move] * pow_table[right_move])
```

数学の解き方で言えば、もう一つ、
次のサイトでいう、書き込み方式で解く場合がある  
https://manabitimes.jp/math/962#4  

例えば、`grid[m][n]`への到達するには、  
`grid[m - 1][n]`から下に行くか、`grid{m][n - 1]`から右に行くか
の2つの方法があり得る。

よって、道順の場合の数を`route[i][j]`とおくと、  
`route[i][j] = route[i - 1][j] + route[i][j - 1]`  
と表せる。

### 書いたコード 3
```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        routes = [[0] * n for _ in range(m)]

        for row in range(m):
            for col in range(n):
                if row == 0 or col == 0:
                    routes[row][col] = 1 
                else:
                    routes[row][col] = routes[row - 1][col] + routes[row][col - 1]
        
        return routes[m - 1][n - 1]
```
時間計算量：`O(mn)` 二重ループにより、処理が`m × n`のオーダーだけ存在する  
空間計算量：`O(mn)` 値を格納する行列`routes`が`m × n`行列のため
