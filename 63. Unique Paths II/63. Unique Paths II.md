## Step.0
まずは自力で解く  
問題の理解から  

前問 Unique Pathsに、障害物があるという条件が追加された  
障害物のある`m × n`gridで、左上から右下までの最短の道順としてあり得る場合の数を答える  

前問では、はじめに数学の問題と捉えて、Combinationを使って解いたが、  
今回では、障害物があるので、その個数、位置によってかなり複雑になる  
例えば、障害物が一か所だけなら、(障害物がない場合での場合の数) - (障害物の位置を通るようにした場合での場合の数)  
で求められるが、2個以上だと、場合分けが煩雑になる、  
できるかもしれないがめんどくさい  
コードで書くのには向いていない  

なので、Combinationではなく、書き出し方式の方が勝機がありそう  
障害物の位置までの道順の個数を0で固定してしまえば、今までと同じ、  
つまり、`grid[m][n]`までの道順の個数を`num_paths[m][n]`と置いてみると、  

 - `obstacleGrid[m][n]` == 1 ならば、`num_paths[m][n] = 0`
 - そうでないなら、`num_paths[m][n] = num_paths[m - 1][n] + num_paths[m][n - 1]`

コードに起こす。始めに、0行目、0列目を処理してから、残りを処理する形にした。  
まとめると条件分岐がややこしい・読みづらくなると感じたので。  

### 書いたコード 1
```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        num_rows = len(obstacleGrid)
        num_cols = len(obstacleGrid[0])

        num_paths = [[0] * num_cols for _ in range(num_rows)]

        for row in range(num_rows):
            if obstacleGrid[row][0] == 1:
                break
            num_paths[row][0] = 1
        
        for col in range(num_cols):
            if obstacleGrid[0][col] == 1:
                break
            num_paths[0][col] = 1

        for row in range(1, num_rows):
            for col in range(1, num_cols):
                if obstacleGrid[row][col] == 0:
                    num_paths[row][col] = num_paths[row - 1][col] + num_paths[row][col - 1]

        return num_paths[num_rows - 1][num_cols - 1]
```
`AC`  
入力マップが、`m × n`行列とすると、  
時間計算量：マップの大きさに依存する、`O(m × n)`  
空間計算量：マップと同じ大きさの行列`num_paths`を保持する、`O((m × n)`
