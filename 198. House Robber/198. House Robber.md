## Step.0
まずは自力で解く  
問題の理解から  

大事な設定を抜きとると、入力リストから、  
連続しないように要素を取ったsubsequenceの総和のうち、最大のものを出力する問題  

制約：  
 - 入力の長さは1以上100以下  
 - 各要素は0以上400以下  

漸化式チックにして考えてみる  
a_n = `n`番目の要素を採用した、subsequenceのうち最大の総和  
b_n = `n`番目の要素を採用しない、subsequenceのうち最大の総和  

こうすると、各要素は全て非負であることから、  
漸化式は、  
 - `a[0] = nums[0]`
   - (0番目の要素を採用する)
 - `b[0] = 0`
   - (0番目の要素を採用しない)
 - `a[n] = b[n - 1] + nums[n]`  
   - (n番目の要素を採用するということは、(n - 1)番目の要素は採用しないという事なので、  
     その内総和最大となるのはb[n - 1]に相当する)
 - `b[n] = max(a[n - 1], b[n - 1])`
   - (n番目の要素を採用しないので、(n - 1)番目の要素を採用するかしないかで択となる
   - よって、より大きい方を採用する)
    
となる。  最後に、`max(a[len(nums) - 1], b[len(nums) - 1])`を出力したらok  

この場合、時間計算量は、要素を`N`個とすると、`2 * N`個分の処理を行うことになるので、`O(N)`  
空間計算量も同様に、長さ`N`のリストを2つ保持するので、それらは入力の長さに比例し、`O(N)`  

更新に使用しているのは、一つ前の値と入力のみ、  
なので、リストではなく変数だけで計算し空間計算量を`O(1)`にすることもできる  

コードに起こしてみる  
変数名は、設定意図を考慮して、次のようにする    
a : max_subsequence_sum_with_tail  
b : max_subsequence_sum_without_tail  

問題の制約的に入力が空ではないことが保証されているが、  
空でないことを確認せず`nums[0]`にアクセスするのに少し引っかかったので、  
はじめに空でないことの確認を入れた  

...と思ったけど、逆に何の意図で入れるのかと突っ込まれると、完全に無駄なことをしていますとなってしまうから、  
削除しました  

### 書いたコード 1 
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        if nums is None:
            return 0

        length_nums = len(nums)
        max_subsequence_sum_with_tail = [0] * length_nums
        max_subsequence_sum_with_tail[0] = nums[0]
        max_subsequence_sum_without_tail = [0] * length_nums

        for index in range(1, length_nums):
            max_subsequence_sum_with_tail[index] = max_subsequence_sum_without_tail[index - 1] + nums[index]
            max_subsequence_sum_without_tail[index] = max(max_subsequence_sum_with_tail[index - 1], max_subsequence_sum_without_tail[index - 1])
        
        return max(max_subsequence_sum_with_tail[length_nums - 1], max_subsequence_sum_without_tail[length_nums - 1])
```
`AC`  

後、漸化式をまとめてしまえば、  
 - `b[n] = max(b[n - 1], b[n - 2] + nums[n])`

となるから、一つ前と、二つ前に`nums[n]`を足したもののうち大きい方を採用すればよいともなる  
こちらの方が使用メモリが半分になる

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        length_nums = len(nums)
        max_subsequence_sum_without_continuously = [0] * length_nums

        max_subsequence_sum_without_continuously[0] = nums[0]
        if length_nums > 1:
            max_subsequence_sum_without_continuously[1] = max(nums[0], nums[1])

        for index in range(2, length_nums):
            max_subsequence_sum_without_continuously[index] = max(max_subsequence_sum_without_continuously[index - 1], max_subsequence_sum_without_continuously[index - 2] + nums[index])
    
        return max_subsequence_sum_without_continuously[length_nums - 1]
```

### 書いたコード 3
```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        if not nums:
            return 0

        robbed_last = 0
        skipped_last = 0
        for num in nums:
            robbed_last, skipped_last = skipped_last + num, max(robbed_last, skipped_last)
        
        return max(robbed_last, skipped_last)
```

同時に代入すれば、一時変数を生成せずに済むが、可読性が下がる  
(どの変数にどの値が入って更新されるのか分かりにくくなるということ)  
参考 : https://github.com/kitano-kazuki/leetcode/pull/35#discussion_r3116836691  

ということで、同時代入しない場合も書く  

### 書いたコード 4
```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        robbed_last = 0
        skipped_last = 0
        
        for num in nums:
            prev_robbed_last = robbed_last
            robbed_last = skipped_last + num
            skipped_last = max(skipped_last, prev_robbed_last)
        
        return max(robbed_last, skipped_last)
```
