## Step.0
まずは自力で解く  

文字列の中で、1文字だけ使用されている文字のうち、一番先頭に近い文字のインデックスを答える問題  
&nbsp;  
重複があるかを考えなくてはいけないので、文字列の最後まで見る必要がある  
まず思いついたのは、リストか辞書のどっちを使うか  
セットは向いてなさそう...重複部分を抜きにして考えられるかもしれないが、インデックスが分からなくなる  
初めに思いついた辞書による解法でトライ  
&nbsp;  
思いついた解法
 - 入力の文字列`s`を、`Key`:アルファベット、`Value`：インデックスとした辞書に入れる
 - これにより、辞書に出現文字とその出現場所がまとめられる
 - 出現回数が1回のアルファベットのみ取り出し、その内インデックスが最小のものを`return`  
 - 出現回数1回のアルファベットがないなら`-1`を`return`

&nbsp;  
コードに起こしてみる
### 書いたコード1
```python
from collections import defaultdict

class Solution:
    def firstUniqChar(self, s: str) -> int:
        seen_char_time = defaultdict(list)
        
        for i in range(len(s)):
            seen_char_time[s[i]].append(i)
        
        unique_index = []
        for char, index in seen_char_time.items():
            if len(index) == 1:
                unique_index.append(index[0])
        
        if unique_index:
            return min(unique_index)
        else:
            return -1
```
AC  
解き終わってから思うのもあれだが、変数名がちょっとしっくりこない(特に`seen_char_time`)  
これで他の方にも意図が伝わるのか微妙なところ  

時間計算量：`O(N)`  
 - 1つ目の`for`文...`append`に、`O(1)`、これを入力文字列の長さ分実行するので、`O(N)`  
 - 2つ目の`for`文...最悪の場合(入力文字列がすべて異なるアルファベットで構成)、`Key`が`N`個になるので、`O(N)`  
 - 最後の`if`文...`unique_index`の長さは最大で`N`、よって`O(N)`  

合計して`O(N)+O(N)+O(N) = O(3N) = O(N)`  
空間計算量：`O(N)`
最悪の場合、辞書、`unique_index`ともに`N`個の要素を格納する

`Counter`関数で文字の出現回数をカウントしてくれる、便利！  

最初に宣言する辞書の名前について、「出現頻度を数える」という意味で`character_frequency`はありだなと感じた  

これまでのポイントをまとめて、`Counter`を使用した場合のコードを書いてみる  
`enumerate`を用いることで、入力の文字とそのインデックスを一緒に取り出して扱うことが出来る  

### 書いたコード2
```python
from collections import Counter

class Solution:
    def firstUniqChar(self, s: str) -> int:
        character_frequency = Counter(s)
        
        for index, character in enumerate(s):
            if character_frequency[character] == 1:
                return index

        return -1 
```
コード1の時より、何をしているかが直感的に分かりやすくなった
