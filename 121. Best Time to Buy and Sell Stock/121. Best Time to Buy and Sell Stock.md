## Step.0
まずは自力で解く  
問題の理解から  

株で一番高い利益を出せるときの、利益を求める問題  
問題的にはセーフかもしれないが、未来の情報を見るのは現実の株の考えに合っていないので、したくない  
（`i`日目の値を見てるときに、`i + 1`日目以降の値をもとに判断するということはしたくない） 

一つアイデアを思い付いた  
 - `i`日目まで見た中で、最小値のインデックス`min_price_index`と最大値のインデックス`max_price_index`を保持しておく
 - ただし、`min_price_index < max_price_index`である  
 - `i + 1`日目の要素を見て、最大値を更新できるかを調べる
   - 更新されないなら、そのまま次の要素を見る
   - 更新できるなら、`max_price_index = i + 1`と更新後、
   - `min_price_index`を`min(prices[:i + 1])`となるインデックスで更新
 - これを繰り返す

初期値は、はじめに`prices[i] < prices[i + 1]`となるところに設定できるか  
最小値の更新するところで、スライスで新しくリストを作っているし、最小値の探索に`O(N)`が毎回かかるのはいただけない  
オーダーとしては、`O(N^2)`になってしまうな  

入力の長さは最大10^5ということなので、実行にかかる時間の見積もりは、  
最大値の比較更新に2ステップほど、最小値更新には、要素`i - 1`の比較で`i - 1`ステップほど  
よって合計`i + 1`ステップほどで、これを`i = 1,...,10^5`まで足し合わせると  
大体`10^5 * 10^5 / 2` = `5 * 10^9`ステップ = `500s`になってしまう  

空間計算量も、先ほどの書いたように、毎回分割リストを書いていて、`O(N^2)`に...

一旦書いてみる  

### 書いたコード 1
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        days = len(prices)
        max_price_day = 0
        min_price_day = 0

        for day in range(days - 1):
            if prices[day] < prices[day + 1]:
                max_price_day = day + 1
                min_price_day = day
                break
        
        for day in range(max_price_day, days):
            if prices[max_price_day] < prices[day]:
                max_price_day = day
                sub_prices = prices[:day - 1]
                min_price = min(sub_prices)
                min_price_day = sub_prices.index(min_price)
        
        profit = prices[max_price_day] - prices[min_price_day]
        
        return max(0, profit)
```

### 書いたコード 2
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0

        for price in prices:
            if price < min_price:
                min_price = price
            elif price - min_price > max_profit:
                max_profit = price - min_price
        
        return max_profit
```

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if prices is None:
            return 0

        min_price = float('inf')
        max_profit = 0

        for price in prices:
            min_price = min(min_price, price)
            max_profit = max(max_profit, price - min_price)
        
        return max_profit
```
