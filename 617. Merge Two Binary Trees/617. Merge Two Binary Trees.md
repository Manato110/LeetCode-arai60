最初に思いついたのはDFS × recursionの解法  
二つの木の足し合わせを、  
 - 根の値の足し算(片方のみ存在ならその値を入れる)
 - 左側の部分木の足し合わせ
 - 右側の部分木の足し合わせ

と問題を分割していけばよい、一番イメージしやすかった  

### 書いたコード 1 (DFS × recursion)
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        if root1 is None:
            return root2
        if root2 is None:
            return root1
        
        merged_root = TreeNode(root1.val + root2.val)
        merged_root.left = self.mergeTrees(root1.left, root2.left)
        merged_root.right = self.mergeTrees(root1.right, root2.right)

        return merged_root
```
このコードを書き始めてからは、4分ほどで書けた  
時間計算量 : `O(N)`
空間計算量 : `O(N)`

他の解法を考えたがいい案がすぐに出なかったため、Step.1に移行  

## Step.1
他の方々のPRを見て、他の解法も考えていく  

DFS × iterativeの場合  
Geminiに尋ねて出力されたコードをアレンジ  
元コードは`root1`を上書きして、`root2`を吸収合併していく感じだったが、  
入力を破壊してしまうので、マージ後のノードを別途作成するようにした  
多少必要メモリが増えるが、許容範囲ではないだろうか  

足し合わせる予定のノードのペアと、足し合わせ後のノード位置をタプルでスタックに保持していく  
コードは長くなるが、これも何をしたいのかが分かりやすい  

### 書いたコード2 (DFS × iterative)
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, right=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root1:
            return root2
        if not root2:
            return root1
        
        merged_root = TreeNode(root1.val + root2.val)

        merged_nodes_pairs = [(merged_root, root1, root2)]

        while merged_nodes_pairs:
            merged_node, node1, node2 = merged_nodes_pairs.pop()
            
            if node1.left and node2.left:
                merged_node.left = TreeNode(node1.left.val + node2.left.val) 
                merged_nodes_pairs.append((merged_node.left, node1.left, node2.left))
            elif node1.left:
                merged_node.left = node1.left
            elif node2.left:
                merged_node.left = node2.left
            
            if node1.right and node2.right:
                merged_node.right = TreeNode(node1.right.val + node2.right.val) 
                merged_nodes_pairs.append((merged_node.right, node1.right, node2.right))
            elif node1.right:
                merged_node.right = node1.right
            elif node2.right:
                merged_node.right = node2.right
        
        return merged_root
```

BFSでもトライ  
BFS × iterativeで考えてみる  
こちらは、コード2で、スタック(LIFO)からキュー(FIFO)に変えたらすぐにできる  
処理予定のペアを入った順にやるのか、最後に入ったものからやるのかの違い  

### 書いたコード3 (BFS × iterative)
```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, right=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root1:
            return root2
        if not root2:
            return root1
        
        merged_root = TreeNode(root1.val + root2.val)

        merged_nodes_pairs = deque([(merged_root, root1, root2)])

        while merged_nodes_pairs:
            merged_node, node1, node2 = merged_nodes_pairs.popleft()
            
            if node1.left and node2.left:
                merged_node.left = TreeNode(node1.left.val + node2.left.val) 
                merged_nodes_pairs.append((merged_node.left, node1.left, node2.left))
            elif node1.left:
                merged_node.left = node1.left
            elif node2.left:
                merged_node.left = node2.left
            
            if node1.right and node2.right:
                merged_node.right = TreeNode(node1.right.val + node2.right.val) 
                merged_nodes_pairs.append((merged_node.right, node1.right, node2.right))
            elif node1.right:
                merged_node.right = node1.right
            elif node2.right:
                merged_node.right = node2.right
        
        return merged_root
```

BFS × recursion
そもそもBFSを再帰で実装する印象がない  
ただ、練習のために実装してみる  

実装するとしたら、同じ深さのノードペアたちを保持するリストを持っておいて、それを順に処理する  
終わったら再帰で深さを一つ大きくする...という感じか  
geminiに書いてもらったが、上のコード達の方が見やすいように感じる  

### 書いたコード 4 (BFS × recursion)
```python
class Solution:
    def mergeTrees(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root1:
          return root2
        if not root2:
          return root1

        merged_root = TreeNode(root1.val + root2.val)

        def merge_nodes(same_depth_merged_nodes):
            if not same_depth_merged_nodes:
                return
            
            next_depth_merged_pairs = []
            for merged_node, node1, node2 in same_depth_merged_nodes:
                if node1.left and node2.left:
                    merged_node.left = TreeNode(node1.left.val + node2.left.val)
                    next_depth_merged_pairs.append((merged_node.left, node1.left, node2.left))
                elif node1.left: merged_node.left = node1.left
                elif node2.left: merged_node.left = node2.left

                if node1.right and node2.right:
                    merged_node.right = TreeNode(node1.right.val + node2.right.val)
                    next_depth_merged_pairs.append((merged_node.right, node1.right, node2.right))
                elif node1.right: merged_node.right = node1.right
                elif node2.right: merged_node.right = node2.right
            
            merge_nodes(next_depth_merged_pairs)

        merge_nodes([(merged_root, root1, root2)])
        return merged_root
```
