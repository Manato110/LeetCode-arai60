## Step.0
まずは自力で解く  

昇順ソートの済みのリストから二分木を作成する  
作成後の二分木は、DFSで左優先に探索したときにノードの値が昇順になるように並ぶようにする  
さらに、そのような二分木のうち、深さの最大値が最小となるようにしたい  
専門用語で言うと平衡二分探索木になるようにしたい  

まあ、素直に木を作っていってみよう  
一番最初に思いついたのは、再帰で問題を分割して解く方法  

思いついたアイデア
 - 入力されたリスト`num`をより小さい要素の集合`numleft`・中央値・中央値より大きい集合`numright`の3つに分割する
 - 中央値を値に持つノードを作成
 - 作成したノードを親として...
   - 左側を引数`numleft`として関数を再起呼び出し
   - 右側を引数`numright`として関数を再起呼び出し

コードに起こしてみる  
### 書いたコード 1
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        
        median = len(nums) // 2
        root = TreeNode(nums[median])

        root.left = self.sortedArrayToBST(nums[:median])
        root.right = self.sortedArrayToBST(nums[median + 1:])

        return root
```
`AC`   
再帰は木が生成されるイメージをしやすいので好み  

時間計算量：`O(N)`入力リストの長さだけ関数を呼び出し

### 書いたコード2
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        root = TreeNode()
        list_to_tree = [(0, len(nums) - 1, root)]

        while list_to_tree:
            left, right, node = list_to_tree.pop()
            middle = (left + right) // 2
            node.val = nums[middle]

            if left <= middle - 1:
                node.left = TreeNode()
                list_to_tree.append((left, middle - 1, node.left))
            
            if middle + 1 <= right:
                node.right = TreeNode()
                list_to_tree.append((middle + 1, right, node.right))
        
        return root
```

DFS × iterative(stack)が出来れば、queueに変えたらBFS × iterativeも書けるはず  
ということでBFSの場合も書く  

### 書いたコード3
```python
from collections import deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        root = TreeNode()
        list_to_tree = deque([(0, len(nums) - 1, root)])

        while list_to_tree:
            left, right, node = list_to_tree.popleft()
            middle = (left + right) // 2
            node.val = nums[middle]

            if left <= middle - 1:
                node.left = TreeNode()
                list_to_tree.append((left, middle - 1, node.left))
            
            if middle + 1 <= right:
                node.right = TreeNode()
                list_to_tree.append((middle + 1, right, node.right))
        
        return root
```
