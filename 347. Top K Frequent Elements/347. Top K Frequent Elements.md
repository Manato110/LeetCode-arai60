## Step.0
まずは自力で考えてみる  
各数字の出現回数を記録して、最後に出現回数上位k個の数字を答えとなるリストに入れていけばいけそう  
&nbsp;  
上のアイデアをもとにコードに落とし込めるか検討  
入力リストの各数字の出現回数について記録するがあるなら、リストは向いてなさそう...?  
出現する数字 = `Key`、出現回数 = `Value`とした辞書型の方が管理しやすいと判断  
入力リストを前から見て、初めて見る数字なら新たにKeyを作成、見たことある数字ならValueを増やしていく
&nbsp;  
辞書が完成したら、出現回数上位k個を取り出す  
先に辞書を出現回数 = `Value`をもとにソートしたほうが、後でほしい`Key`が順番に並んでやりやすそう  
...が、`sorted`関数を使ってそのまま  
&nbsp;  
```python
sorted_frequency = sorted(frequency, reverse=True)
```
としたら答えが合わない...  
(ここだけネット検索を使用しています、すみません...)  
やり方が分からず調べると、key引数の指定が必要と判明  
いままで昇順か降順で並べることしかしなかったので、key引数,lambda式をここで始めて学ぶ  
(参考文献：https://qiita.com/Tadataka_Takahashi/items/94a37047020328c2fe79)  
今回は辞書内ペア`Key`, `Value`のうち、2番目`Value` = `x[1]`でソートするので、次のようになる  
```python
sorted_items = sorted(frequency.items(), key=lambda x: x[1], reverse=True)
```
あとはソートしたところからk個`Key`を取り出して終わり  
&nbsp;  
### 実際に書いたコード
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:

        frequency = {}

        for num in nums:
            if num in frequency:
                frequency[num] += 1
            else:
                frequency[num] = 1

        sorted_frequency = sorted(frequency.items(), key = lambda x: x[1], reverse = True)
        ans = [item[0] for item in sorted_frequency[:k]]
        
        return ans
```
時間計算量：`O(NlogN)`　`sorted`関数におけるソート部分で`O(NlogN)`  
空間計算量：`O(N)`　　　入力リストの要素をすべて見ていくため、比例

実際にこのようなコードがどのような場面で使用されるのか?ということも考察するのが良いかも  
ネットサイト検索回数上位k個はどれ?みたいな  
(https://github.com/potrue/leetcode/pull/9/changes#r2083755650)  
&nbsp;  

ヒープを使うと時間計算量が短くなるらしい  
ヒープに(`数字`, `出現回数`)のタプルで格納し、出現回数上位k個を保持していく形にする

### 書いたコード
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        frequency = {}
        for num in nums:
            if num in frequency:
                frequency[num] += 1
            else:
                frequency[num] = 1
                
        heap = []

        for num, count in frequency.items():
            heapq.heappush(heap, (count, num))

            if len(heap) > k:
                heapq.heappop(heap)
        
        ans = []
        while heap:
            ans.append(heapq.heappop(heap)[1])
        
        return ans
```
時間計算量：`O(Nlogk)`  
空間計算量：`O(N)`
