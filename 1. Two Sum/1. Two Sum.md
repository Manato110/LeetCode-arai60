## Step.0
アイデア1  
足して`target`となるペアを見つければよいので...  
 - 要素を手前から順にみていく( `= nums[i]`とする)
 - `i`番目の要素を見ているとき、その一つ右隣りから順に最後まで要素を見る(`= nums[j]`とする)
 - `nums[i] + nums[j] = target`となったら`nums`のインデックスのペア`[i, j]`を出力して終了  

これでリスト内ですべての要素ペアを見ることが出来ている  
ただ、2重ループで明らかに時間計算量が`O(n^2)`となる...  
要素の保持はしていないので、空間計算量は`O(1)`  
&nbsp;  
とりあえず間違いなくWAにならないアイデアと感じたため、コードに起こすことにした  
より効率の良いコードに後のStepで修正検討  

### 書いたコード1
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        nums_size = len(nums)
        
        for i in range(nums_size):
            for j in range(i + 1, nums_size):
                if nums[i] + nums[j] == target:
                    return [i, j]
```

## Step.1
アイデア2  
とにかく、2重ループ部分を解消したい  
問題の分類からも、hashmapを使用するとよいのだろう... 
先ほどのコードでムダに行っていると思ったのは、リストの後ろの方の要素ほど、何回もアクセスしている点  
一度見た要素と位置を記憶しておけば何かできそう  
&nbsp;  
少し考えて、思いついたアイデアが下の通り  
 - 今まで見た要素とそのインデックスをメモする辞書を用意
 - 要素を手前から順にみていく
 - 今見ている要素と`target`との差`complement`を求めて、その値が辞書の中にあるかを検索
 - もしあったら、その値のインデックスを取得して、見ている要素のインデックスとペアにして出力

実装にあたり、他の方のPRを参考にした  
https://github.com/h-masder/Arai60/blob/1_Two_Sum/1_Two_Sum/memo.md  
https://github.com/dorxyxki/arai60/tree/1-two-sum/1  

他の方のコードを見て気づいたが、自分のコードでリストの長さを`nums_size`と変数においた部分を削除した  
マジックナンバーとなりかねない...  
&nbsp;  
pythonでは、`enumerate`関数でリストのインデックスと要素をまとめて取得ができる  
これを使って書いてみる

### 書いたコード2
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen_num_to_idx = {}

        for idx, num in enumerate(nums):
            complement = target - num
            
            if complement in seen_num_to_idx:
                return [seen_num_to_idx[complement], idx]
            
            seen_num_to_idx[num] = idx
```
時間計算量：`O(N)`　辞書の検索は平均して`O(1)`、これを最悪の場合リストの長さ分おこなう  
空間計算量：`O(N)`　最悪の場合、リストの長さ分辞書で値を保持する

## Step.2
書いたコード2に例外処理を追加して、より実践的なコードにしていく  
終わったら、見ずにミスなく3回コードを書く  
&nbsp;  
今回は、必ず和が`target`に一致するペアが存在することが保証されていた  
この部分が保証されていないとして、例外処理を書いてみる  
つまり、すべての組み合わせを調べても和が一致しなかったことを出力する  
&nbsp;  
pythonでは、意図的に例外処理を入れるときは、`return`ではなく`raise`で記述するらしい  
https://popinsight.jp/blog/?p=91995  
`return`と混合しないで済むし、こっちで書いてみる

### 書いたコード3
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen_num_to_idx = {}

        for idx, num in enumerate(nums):
            complement = target - num
            
            if complement in seen_num_to_idx:
                return [seen_num_to_idx[complement], idx]
            
            seen_num_to_idx[num] = idx
        
        raise ValueError(f"No two numbers sum up to the target: {target}")
```
書いたコード3を、見ずにミスなく3回コードを書く
