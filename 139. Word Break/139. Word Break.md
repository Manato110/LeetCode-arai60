## Step.0
まずは自力で解く  
問題の理解から  

`wordDict`にある単語を無制限に使用して、ターゲット文字列`s`を作ることが出来るかを判定する  

ターゲットとなる文字列があるなら、0からターゲットに一致するように`wordDict`から単語を組み合わせるより、  
ターゲットから`wordDict`の単語との一致部分を消していって、最終的に全て一致したと確認する方が近道  
ゴールから考える方が早い  

一番最初に思いついた解法は、先頭にある単語が`wordDict`に一致するのかを毎回調べる方法  
BFS的に、FIFOのqueueにターゲット文字列を格納し、  
`wordDict`内の単語と先頭が一致していれば、一致部分を削除した文字列をqueueに入れる  

`s`が最大`n`個の単語に分割でき、`wordDict`が`m`個の単語を保持しているなら、  
最大で`O(nm)`の操作で終了する  
`s`が最大300、`wordDict`が最大1000個の単語なので、最悪の場合、概算で300000 = 3 * 10^5回の実行ステップ  
時間で言うと3 * 10^5 / 10^7 = 30ms  
オーダーで見ると大きいが、制限内に収まりはしそう  

それよりも空間計算量が大きくなりそう  
先頭が`wordDict`の要素すべて一致する場合だと、かなりqueueに追加されることになり、使用メモリが莫大になる  
例えば、`s = aaaaaaa....a`, `wordDict = [a, aa, aaa, ..., aaaaaaaa]`みたいなとき　　
`wordDict`の単語で文字列を削るには、スライスでできるが、時間のかかる操作なのであまりしたくはない  

queueには、スライス後の文字列ではなく、スライス後の文字の開始位置を入れることにしたら、スライスせずに済みそう  

### 書いたコード 1
```python
from collections import deque


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        target_s = s
        len_target_s = len(s)
        target_queues = deque([0])

        while target_queues:
            target_s_start = target_queues.popleft()
            if target_s_start == len_target_s:
                return True
            
            for word in wordDict:
                if target_s[target_s_start : target_s_start + len(word)] == word:
                    target_queues.append(target_s_start + len(word))
        
        return False
```

```python
from collections import deque


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        length_s = len(s)
        start_positions = deque([0])
        visited = set()

        while start_positions:
            start_position = start_positions.popleft()
            if start_position in visited:
                continue
            visited.add(start_position)

            if start_position == length_s:
                return True
            
            for word in wordDict:
                if s[start_position : start_position + len(word)] == word:
                    start_positions.append(start_position + len(word))
        
        return False
```
計算量について、`n = len(s), m = len(wordDict), l = max([len(word) for word in wordDict])` とおくと、  
最悪の場合、時間計算量：`O(nml)` 開始位置`n`箇所それぞれについて、for文で高々`O(ml)`回の比較  
空間計算量：`n`個の開始位置がsetにメモされる

```python
        @lru_cache(None)
        def word_check(start):
```

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        reachable_memo = [-1] * len(s)

        def reachable(index: int) -> bool:
            if index == -1:
                return True

            if reachable_memo[index] != -1:
                return bool(reachable_memo[index])

            for word in wordDict:
                word_len = len(word)
                start = index - word_len + 1

                if start < 0:
                    continue
                
                if reachable(start - 1):
                    if s[start : index + 1] == word:
                        reachable_memo[index] = 1
                        return True

            reachable_memo[index] = 0
            return False

        return reachable(len(s) - 1)
```

## Step.2  
`startswith`関数を使用する  
```python
from collections import deque


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        length_s = len(s)
        start_position = 0
        start_positions = deque([start_position])
        visited = set()

        while start_positions:
            start_position = start_positions.popleft()
            if start_position in visited:
                continue
            visited.add(start_position)

            if start_position == length_s:
                return True
            
            for word in wordDict:
                if s.startswith(word, start_position):
                    start_positions.append(start_position + len(word))
        
        return False
```
