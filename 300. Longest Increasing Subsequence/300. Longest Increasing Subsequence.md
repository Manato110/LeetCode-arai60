## Step.0
まずは自力で解く  
問題の理解  
考えられる狭義単調増加な部分列のうち、長さが最大のものの長さを出力する問題  


すぐに思いつくのは、狭義単調増加な部分列として考えられるものを全て列挙しながら考えていく方法  
リストの要素を前から見ていって、  
その要素から始まる部分列・部分列の末尾が見ている要素より小さい部分列  
に追加することが出来る  

気がかりは、リストがもともと狭義単調増加であったりする場合だと、保持する部分列が多くなりすぎること  
とりあえず思いついたので書いてみる  

### 書いたコード 1
```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        length_and_tail_number = []
        
        for num in nums:
            for length, tail_num in length_and_tail_number:
                if tail_num < num:
                    length_and_tail_number.append((length + 1, num))
            
            length_and_tail_number.append((1, num))
        
        return max(length_and_tail_number, key = lambda x:x[0])[0]
```
`Memory Limit Exceeded`になった  
例えば、リストが狭義単調増加の場合、毎ステップで2 + α倍されるので、保持するリストの量は`O(2^N)`  
さすがにこれではメモリが足りない  
制約で、要素数は最大2500、数字一つの保持に28byte必要なので、  
大体28 * 2 ^ 2500 byte  
1GB = 2^30 byteであることを考えると、大体80~90GB必要というとんでもないメモリ使用量になってしまう  

その後も考えたが、良い解法が思い浮かばなかった

メモするのは、  
`max_subsequence_length[i]`：`num[i]`を末尾とする狭義単調増加部分列の長さ  
`max_subsequence_length[i] = 1`で初期化  
前に見たリストの数字`num[previous_index]`より、  
後の数字`num[current_index]`の方が値が大きい場合、長さを`+!`できる可能性がある  
つまり、  
```python
if num[current_index] > num[previous_index]:
  max_subsequence_length[current_index] = max(max_subsequence_length[current_index], max_subsequence_length[previous_index] + 1)
```
### 書いたコード 2  
```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        nums_length = len(nums)
        subsequence_lengths = [1] * nums_length

        for current_index in range(nums_length):
            for previous_index in range(current_index):
                if nums[current_index] > nums[previous_index]:
                    subsequence_lengths[current_index] = max(subsequence_lengths[current_index], subsequence_lengths[previous_index] + 1)
        
        return max(subsequence_lengths)
```
`AC`  
時間計算量：リストのある要素を見るときに、その手前の要素を全て検討している  
この部分の二重ループで、実行ステップが`N(N+1)/2`回発生　⇒　`O(N^2)`  
空間計算量：保持するのは入力の長さ分の要素しかない`subsequece_length`のみ　⇒　`O(N)`  

コードが良くなった...と思うが、  
再帰やDFS, BFSみたいに、どのように実行が進んでいくかというイメージがDPではなかなかできていない  
この後の問題を通してできるようになるのだろうか  

https://github.com/kitano-kazuki/leetcode/blob/300-longest-increasing-subsequence/memo.md  
二分探索によって、時間計算量`O(NlogN)`にしていた  
今まで二重ループで`O(N^2)`だったところを、内側のループ部分で`O(logN)`になるようにしたもの  

次のように定義する  
`subsequence_tails[i] = 長さ i+1 の増加部分列を作れるとき、その末尾としてあり得る最小の数値`  
最小の数値を保持しているので、`subsequence_tails`は単調増加列であることが保証される  
そのため、`nums`の要素を一つずつ見ていったときに、  
`subsequence_tails`のどこを更新できるかを二分探索によって調べることが出来る  

これによって、内側のループで`logN`回の探索で済む  

### 書いたコード 3
```python
from bisect import bisect_left


class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        nums_length = len(nums)
        subsequence_tails = [] # 長さ i+1 の狭義単調増加部分列を作れるとき、その末尾としてあり得る最小の数値

        for num in nums:
            subsequence_length = bisect_left(subsequence_tails, num) # numを末尾としたときに更新できる狭義単調増加部分列の長さ

            if subsequence_length < len(subsequence_tails):
                subsequence_tails[subsequence_length] = num
            else:
                subsequence_tails.append(num)
        
        return len(subsequence_tails)
```

### 書いたコード 4
```python
from typing import List


def bisect_left(array: List[int], target: int, left: int, right: int) -> int:
    while left < right:
        middle = (left + right) // 2
        if array[middle] >= target:
            right = middle
        else:
            left = middle + 1

    return left

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        nums_length = len(nums)
        subsequence_tails = []

        for num in nums:
            subsequence_length = bisect_left(subsequence_tails, num, 0, len(subsequence_tails))

            if subsequence_length < len(subsequence_tails):
                subsequence_tails[subsequence_length] = num
            else:
                subsequence_tails.append(num)
        
        return len(subsequence_tails)

```
