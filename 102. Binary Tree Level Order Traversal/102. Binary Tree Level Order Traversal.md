同じ深さのノードを同じリストに入れていく、最終的にリストのリストを返す  
同じ深さで考えるなら、BFSでやるのが実行する内容的に適任か

 - ノードの値と深さのタプルで見る予定のキューを作る
 - 深さ`d`を考えるときに、空リストを作って、同じ深さのノードを入れていく  
 - ノードの子(深さ`d+1`で次に見るノード達)を次に見るリストとして入れていき、完成したらそれらをまとめてリストにする

リストを作るのではなく、深さを`Key`、ノードの持つ値を`Value`にした辞書(`defaultdict`)の方が書きやすそう

制約  
`The number of nodes in the tree is in the range [0, 2000].`
`-1000 <= Node.val <= 1000`

全てのノードが一回ずつ探索され、空リストの生成は木の深さが`H`だとすると`H`個だけ生成される  
約十数ステップの処理が必要と仮定すると、全体で必要な処理は30000~40000ほど  
実行ステップを`10^7`回/秒とすると、大体3~4msほどに

実際に書いてみる

### 書いたコード 1
```python
from collections import defaultdict, deque

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if root is None:
            return []
        
        same_depth_list = defaultdict(list)
        depth = 0
        worklist = deque([(root, depth)]) # 処理するノードとその深さを保持

        while worklist:
            node, depth = worklist.popleft()
            same_depth_list[depth].append(node.val)

            if node.left is not None:
                worklist.append((node.left, depth + 1))
            if node.right is not None:
                worklist.append((node.right, depth + 1))
        
        return list(same_depth_list.values())
```
`AC`  
時間計算量：`O(N)`  全てのノードを見るため、ノードの個数に比例  
空間計算量：`O(N)`　例えば葉でないすべてのノードが1つの子のみ持つ場合、全ての深さに対してリストを作成する必要がある  

キューではなくスタックにして、DFS×iterativeでも書いてみる  

ただ、この問題では、各深さのノードに対して、左側から右側のノードの順に出力が並ぶ必要がある  
LIFOのスタックなら、先に右側の子ノードをスタックに入れないと、出力の順序が右から左で逆順になってしまうことに注意

同じ深さのノード達をまとめるリスト`current_level_nodes`、
ノードの持つ値をまとめるリスト`values`、  
次に処理する、次の深さのノード達のリスト`next_level_nodes`、  
`current_level_nodes`をまとめる`level_ordedred_list`の3つのリストで管理・処理をおこなう  

`current`は基本的に持つ情報量が少なく、あまり使わないようにしているが、  
今回は`next`とは別に用意する必要があるので、使用するのも許容されるだろう  

```python
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        current_level_nodes = [root]
        level_ordered_list = []

        while current_level_nodes:
            next_level_nodes = []
            values = []

            for node in current_level_nodes:
                values.append(node.val)

                if node.left is not None:
                    next_level_nodes.append(node.left)
                if node.right is not None:
                    next_level_nodes.append(node.right)

            current_level_nodes = next_level_nodes
            level_ordered_list.append(values)
        return level_ordered_list
```

DFS × recursionでの解法にもトライしていた  
この方も言及していたが、問題の内容的にDFSよりもBFSの方が実行される様子がイメージしやすい  

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def levelOrder(self, root: TreeNode | None) -> list[list[int]]:
        if root is None:
            return []

        values = []

        def traverse(node: TreeNode, level: int) -> None:
            if level >= len(values):
                values.append([])
            values[level].append(node.val)

            if node.left is not None:
                traverse(node.left, level + 1)
            if node.right is not None:
                traverse(node.right, level + 1)

        traverse(root, 0)
        return values
```
